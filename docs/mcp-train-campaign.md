# 第五章：疾驰货运列车 / 五章战役

## 范围及入口

按用户选择的移动列车主题，已直接接入五章连续战役。游戏菜单新增 05 / 疾驰货运列车，可通过 `?map=train` 单独进入，或使用 `?map=train&mode=journey` 接续战役。第一、二、三、四章既有隐藏星星区域和难度不变。

## 可玩关卡

五节车厢：尾车、货舱、信号车、控制车、驾驶舱。实际可行走高度为车内 1.5 米和车顶 4.5 米。尾车及控制车各有一段楼梯，车厢间有实体空隙，车顶可跳跃跨缝，也可沿右侧窄桥通行。

五个任务阶段：

1. 清理尾车并夺取门控。
2. 进入货舱，解除安全锁。
3. 登上第三节车顶，关闭干扰器。
4. 下到控制车内部，防守机车控制链路 16 秒；离开正确楼层暂停进度。
5. 进入驾驶舱，清理追兵并确认接应。

共 21 名初始与增援守卫，使用既有突击、远程和重装角色；8 处按楼层判定的补给。没有新增 Boss。敌人可以沿楼梯及连接桥在两层间移动，保留各角色的交战距离；敌人不执行玩家式跨缝跳跃。

机车右侧为可选隐藏星星路线，需要三次窄平台跳跃到 6.9 米落点。跌落列车后返回当前任务阶段入口，保留本次生命、弹药与收集结果，不设置永久失败。

行驶采用随车坐标系：列车、角色与车载碰撞保持局部坐标一致，轨道枕木、城市建筑与窗外环境以约 18m/s 相对后移。显示速度约 65km/h，暂停时运动冻结，恢复检查点保留行驶时间。这是可玩的随车射击关卡，不是独立轨道驾驶、转弯、车厢脱钩或脱轨物理系统。

## 主要文件

- `train-data.js`：五阶段、车厢、楼梯、桥、门禁、刷怪、补给、星星平台。
- `train-navigation.js`：列车局部双层导航与楼梯/桥连接。
- `train-world.js`：列车场景、窗户、车厢标识、城市相对运动、暂停和恢复。
- `app.js`、`arena.js`、`level.js`、`mission.js`、`mission-world.js`、`mission-ui.js`、`radar.js`：实际运行集成。
- `journey.js`、`journey-ui.js`、`campaign.js`、`collectibles.js`、`star-world.js`、`levels.css`：五章流程、旧存档迁移及成就规则。
- `tower-data.js`：原第四章结尾改为章节完成，避免提前声称全战役结束。

## 修复与当前边界

修正楼梯旁掩体阻挡，调整楼梯屋顶开口，解决敌人在楼梯入口、出口及跨车连接处反复折返；将列车高度提示移到顶部中央，避免遮挡任务列表。

当前为直线行驶的固定五车厢布局，玻璃有碰撞但不可击碎，环境建筑为循环生成场景。未开发可驾驶机车、轨道分岔、车厢脱钩、动态关卡拼接或新 Boss。
