- 在车厢门锁前完成原生 E 交互，由阶段 2 自然推进至阶段 3，自动保存 `(0.5,-7.6,0m)`，不是固定入口 `(0,-7.6)`。

- 三窗口击破 1200 HP，记一次 Boss 击杀；实际打开末班列车通道并生成四名撤离守卫。

### 中枢塔 ELEVATOR

- 在核心授权台前完成原生 E 交互，由阶段 2 自然推进至阶段 3，自动保存 `(7,9.2,6m)`，不同于固定入口 `(7,4.6,6m)`。

- 阶段 4 实际生成四名大厅追兵；不在本专项继续清敌并撤离。

初始布置及显式检查点恢复之外，不再写入玩家位置；连续路段逐时间步检查异常水平位移。原地图、碰撞、重力、跳跃、守卫生成、机关计时与伤害逻辑保持真实。

## 2. 实际保存 / 刷新 / 重试

两章 stage 3 / 4 共四个自动检查点，各执行页面刷新继续和死亡→原生重试，合计八次恢复验证：

- 直接使用生产阶段推进自动保存的内容，不另行用测试保存覆盖坐标。
- 核对坐标 / 脚底高度、生命、当前武器、三种基础枪械的弹匣与备弹、击杀、任务时间及阶段守卫数量。
- 恢复后防守进度清空、Boss 非激活、完整一命资格关闭。
- 中枢塔额外核对原维护升降机时钟；Boss 战斗升降台在 stage 3 恢复到 0m、stage 4 恢复到 6m，保留既有阶段级存档语义。

这覆盖四条实际保存路径，不等于穷举所有保存坐标、断电写入失败或多标签页冲突。没有修改 `campaign.js`、`app.js` 或存档格式。

## 3. 玩家可见的目标引导修正

### 道岔锁定后，不再让玩家围着控制器等待

- `switchyard-world.js`：道岔锁定后目标转到青色核心，标签提示“侧面接近核心 · 等待列车破盾”。
- 已锁定或列车行进期间隐藏不能再操作的编号道岔标记，下一轮未锁定的预警期恢复显示。
- `switchyard-ui.js`：明确“从侧面接近青色核心，避开轨道”，并保留列车只破盾、琥珀圈横移躲避的说明。视觉复核后主动分行，避免末尾单字换行。

### ELEVATOR 暴露时，目标指向胸核而非脚下踏板

- `elevator-world.js`：暴露期目标使用实际胸核世界坐标，随 0 / 3 / 6m 楼层变化，标签显示“青色胸核 · 窗口内攻击”。
- 未暴露时仍指向踏板；需要换层时仍指向战斗升降台。
- 不改变武器射线、刀距、暴露时长、升降台速度或伤害。
