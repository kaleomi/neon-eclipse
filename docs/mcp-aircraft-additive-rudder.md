# 飞机鼠标 + A/D 叠加方向舵

## 用户纠正与当前控制

用户明确要求 A/D 也带动飞机转向，能与鼠标叠加加快转向，相当于将 Q/Z 的操作移到 A/D。
本文取代 [上一轮独立观察方案](mcp-aircraft-keyboard-look.md)。上一轮不再是当前行为。

- A 左方向舵，D 右方向舵；不再设置独立镜头观察偏角。
- 鼠标引导航向保持工作，与 A/D 同向叠加时更快，反向时互相抵消部分转向。
- Q/Z 兼容同一方向舵轴，不与同方向 A/D 重复加倍。
- 松开 A/D 停止额外转向，保留键盘已转出的航向；不会返回按键之前的方向。
- 若仍有鼠标航向误差，松手后继续对准剩余目标。
- 左右方向键仍为手动滚转；W/S、Shift/Ctrl、E/C/Esc 和安全机制保持。
- 步行、越野车及游艇 A/D 不变。

## 实现

[flight-rules.js](../flight-rules.js) 新增可选 rudderAssist 输入，与原自动滚转/方向舵分开限幅后叠加。
空中额外偏航率最大 0.2 rad/s；地面使用随速度缩放的转向率，静止不能原地旋转。
stepPlane 返回实际积分的额外航向增量，应用层将其累加到目标航向，避免辅助控制拉回旧航向。
子步内同步偏移目标；旧调用者忽略返回值即可，原 rudder/roll 手动优先接口保留。

## 验证

- 扩充 [test-handling.mjs](../test-handling.mjs)，纳入现有 npm test。
- 左右两个方向、30/60/144 Hz：同向叠加更快、单独键盘有效、松手不拉回、反向输入抵消、暂停冻结和静止不旋转。
- 更新 [test-camera-browser.mjs](../test-camera-browser.mjs)，移除上一轮错误需求的断言。
- 软件 WebGL 浏览器实际起飞、A/D 转向、松手保持、鼠标+A 叠加及左右鼠标对准测试通过。
- 同套浏览器测试保留高速游艇、刹车及开放水域禁止离船验证。
