# 第二阶段：南湾突围单艇交火

## 本轮交付与范围

在 [第一阶段海上追逐](mcp-sea-chase-mission.md) 上加入玩家舰炮、敌艇预警齐射、真实飞行弹体、敌艇击毁和战斗生命周期。
本文件取代第一阶段文档中的「没有枪炮」「敌艇不能被击毁」描述。
当前仍是一艘敌艇、固定入门任务配置，不读取主线战斗难度。多艇分工及海上任务难度分档留作第二阶段后续扩展。

## 操作与玩法

- 原任务入口、180 秒撤离窗口、3 个顺序检查点和撤离区规则不变。
- 按住 F：舰炮自动按装填周期反击射程内的追击艇；采用辅助瞄准，不占用鼠标视角、A/D 船舵或空格制动。
- 舰炮是可旋转的甲板炮塔；炮弹并非即时命中，仍可能打空或被地形阻挡。
- 敌艇先显示橙色锁定线/目标圈和 HUD 倒计时，再发射 3 发炮弹。锁定点确定后不再追踪玩家移动。
- 转向、加减速或利用岛屿遮挡躲避；持续停船会受到炮弹伤害。
- 可以不交火直接脱离，也可以击毁追击艇；两种方式都必须完成检查点并减速进入撤离区。
- 命中尚未击毁的敌艇会暴露位置并重新触发追踪。
- 击毁后敌艇停航、倾斜下沉并冒烟，不再碰撞/追击/开火；短暂残骸只是视觉效果。

## 参数

| 参数 | 玩家舰炮 | 敌艇武器 |
| --- | --- | --- |
| 单发伤害 | 20 | 8 |
| 弹速 | 90 m/s | 65 m/s |
| 开火射程 | 12–180 m | 25–145 m |
| 射击节奏 | 1.6 秒装填，无限弹药 | 1.35 秒锁定预警，3 发齐射、间隔 0.18 秒；齐射后冷却 4.8 秒 |
| 目标耐久 | 敌艇 100，命中 5 发可击毁 | 玩家沿用船体 100，碰撞也会扣除 |

敌艇初次开火至少等待任务开始 4 秒，随后仍有完整预警。
武装敌艇近距离尝试保持约 65 米的射击位置并侧移，避免持续贴身撞击叠加炮击；仍使用现有水域导航和防撞规则。
普通追逐规则构造器保留未武装默认值供旧调用者使用；正式网页的南湾突围入口启用交火。

## 物理与生命周期

- 弹体在创建后的后续更新中飞行与命中，没有发射即伤害或追踪导弹。
- 船体用 3 个圆近似，采用弹体与移动船体之间的相对运动扫掠判定，减少高速穿透。
- 岸线、岛屿、码头按二维水域遮挡挡弹；先遇地形则不会穿过地形伤害目标。
- 在飞弹体最多 24 个，短暂水花/命中特效最多 16 个；渲染使用固定网格池。
- 暂停和失焦冻结弹体、预警、装填、耐久与任务时间，清除按键状态；恢复后需重新按 F 才会继续主动射击。
- 脱离追踪会取消尚未完成的敌艇预警/后续齐射，但已飞出的炮弹仍有危险。
- 击毁敌艇清除剩余在飞弹体与预警；成功、失败、超时、退出或重试也清理战斗状态，防止残留伤害。
- 不更改战役/章节/成就存档，不增加 EXE，不修改飞机或陆地载具武器。

## 界面

玩家/敌艇甲板炮塔、炮口闪光、青色玩家弹体、橙色敌方弹体、锁定线和目标圈、命中水花、敌艇沉没效果。
HUD 显示敌艇耐久、玩家装填状态、射程/遮挡提示、敌方锁定与齐射警告。
击毁后雷达移除敌艇但保留撤离目标；结果面板增加舰炮命中/发射统计。
桌面、短窗口及窄屏重新布局，避免状态面板互相覆盖。

纯规则验证：延迟命中、锁定点不跟踪、真实游艇加速躲避、单轮 24 点伤害、5 发击毁、装填、岛屿挡弹、相对扫掠、击毁不跳过航点、死亡/重试清理。

原飞机鼠标+A/D 叠加转向/高速游艇、原越野车浏览器回归通过。
1280×720、960×640、390×640、390×844 的战斗 HUD 面板无互相重叠。
测试使用软件 WebGL，不代表所有路线已人工验证或 Windows GPU 性能结论。
