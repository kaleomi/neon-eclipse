## 玩法

- **工程兵**：90 HP，无额外装甲；继承正常头部命中规则。工具背包、琥珀头盔和工具臂区分轮廓。非施工期间使用远程守卫式移动与单发琥珀预警射击。
- **施工预警**：启动前有初始等待与现有攻击门控；施工固定 2.5 秒，工程兵停止移动／射击。地面环与线框显示被冻结的部署位置，准星面板显示倒计时，配合顶部提示和既有琥珀音效。
- **有效伤害打断**：施工中任意实际 HP 降低均中断，施工标记立即在下一次游戏更新中清除；至少 3 秒后才可再次尝试。开始施工的帧不偷扣 2.5 秒预警。暂停不推进时间。
- **安全位置**：在工程兵周围 2.5／3.5 米的离散候选点中选择；只允许地面、场地内部，避开障碍、活敌人、玩家、补给和任务终端。自身到施工点必须有视线，不向不安全位置回退。
- **完成前复核**：重新检查位置占用、玩家距离、视线与炮塔数量；玩家靠近施工点、敌人占位、新障碍等可使部署失效，而不是把炮塔生成在角色身体里。
- **数量限制**：最多一处在建、最多一座存活炮塔；本阶段部署系统只允许成功部署一次。摧毁工程兵已建炮塔不会触发无限重建。失败／受击取消不消耗成功配额。
- **独立炮塔**：完成后调用与上一批相同的生成函数，沿用 HP 150、正面承伤 35%、背核 ×2、绿色扫描和 1.2 秒旧目标预警三连扫射，以及底座碰撞／导航失效更新。已完工炮塔不会随工程兵死亡凭空消失，需要独立摧毁。
- **调度边界**：施工开始受现有攻击 gate、待发攻击与炮塔威胁限制，并暂时提高 gate；不是重新定义所有普通守卫的全局物理弹丸上限。已发出的弹丸沿用原有系统。

## 生命周期与存档

- 工程兵死亡／从敌人列表移除：取消未完成施工，清理环、线框、几何和独享材质，不生成炮塔。
- 炮塔击杀：取消待发扫射，移除底座障碍并刷新导航。
- 结束、阶段推进、重置：清除施工记录／成功配额；关卡重置会重建原阶段入口遭遇。
- 检查点保持原先“阶段入口重试”语义：防守中存档重试回到 access 入口，恢复初始六守卫＋固定炮塔，不序列化施工倒计时或场上新增炮塔。严格单章纯刀资格和武器弹药仍由现有规则处理。
