# 世界空间战斗预警：运输站场景对照

日期：2026-09-20；项目：`game/`。

## 本批修改

生产代码只修改 `projectiles.js` 一处：瞄准线透明度从 0.48 提高到 0.75。对照中原线条在亮背景和加浓雾效下偏淡，修改后线条更明确。

保留原来的颜色、端点、单线几何、深度测试、雾效与清理流程，不添加网格、灯光、穿墙标记或屏幕覆盖层。共用该瞄准线的普通敌人及 Boss 均使用新透明度；蓄力环、弹丸和伤害规则没有修改。

## 场景证据

新增 `test-world-cue-audit-browser.mjs`，使用真正的运输站构建器、Three/WebGL 和 `createEnemyProjectiles`，固定突击／远程／重装三个敌人位置。敌人使用现有后备几何模型，不等待外部角色资源加载，也不运行完整 AI。

覆盖 3 档画质 × 4 种环境条件 × 5 种色觉模式，共 60 组。正常条件使用站台雾密度 0.011 和曝光 1.07；暗处、浓雾与亮背景是明确的压力覆盖，分别使用曝光 0.35／降低照明、雾密度 0.045、曝光 2.1，不改游戏实际场景设置。

修改前快照先保存到 `.tools/qa-world-cues-before/`；修改后在 `.tools/qa-world-cues-after/`。每侧保存 20 张均衡档静态预警图、弹丸截图和 `audit.json`。已查看正常／明亮／浓雾对照及暗处高对比模式；局部对照图仅用于查看线条差异。

最终核心验证命令退出码 0，标记 `WORLD_CUES_VERIFIED_EXIT=0`，日志 `.tools/world-cues-verified.log`；IDE 错误／警告诊断为 0。

60 组前后 draw calls、三角形数、预警数量、环境参数一致。该结果不是硬件 FPS 或性能提升承诺。

## 回归与边界

新增材质／生命周期断言与场景审计测试；另修正 `test-input-a11y-browser.mjs` 的设置页导航，让脚本先选择控制／辅助分类及语言控件所属分类，没有删除断言或修改产品输入逻辑。首次额外原生测试因旧脚本等待隐藏的按键控件而失败，记录保留在 `.tools/world-cues-final.log`；导航修正后独立重跑通过，`WORLD_CUES_NATIVE_EXIT=0`，日志 `.tools/world-cues-native-a11y.log`。验证了原生改键持久化与跳跃、保留键拒绝、色觉滤镜／辅助设置、语言切换、模拟手柄移动／开火／切枪／暂停及字幕面板出现；模拟手柄不代表真实设备验收。

- 所有带瞄准线的敌人／Boss 攻击配置：新透明度、原端点、深度测试、雾效、完整蓄力时长、清理释放几何与材质、攻击配置不被改写。
