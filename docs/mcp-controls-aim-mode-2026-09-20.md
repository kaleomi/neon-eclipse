# 操作设置：长按／点按开镜

日期：2026-09-20（Europe/Paris）

## 用户需求与结果

在「设置 → 操作」的灵敏度下方增加「开镜方式」：

- **长按右键**（默认）：按住开镜，松开退出。
- **点按切换**：右键点击一次开镜，再点一次退出；松开鼠标不会关闭。

选择保存到现有 `neon-eclipse.controls.v1` 操作偏好，与灵敏度一起恢复。旧偏好只有灵敏度时默认长按，不会在载入时重写偏好。更改灵敏度不会丢失开镜方式，也不删除旧对象中的其他字段。

## 实现与兼容

- `aim-input.js` 将鼠标与手柄作为独立输入源。鼠标支持长按／点按，手柄 LT 始终保持按住语义；释放其中一个输入源不会错误关闭另一个来源的瞄准。
- `controls-settings.js` 负责读取、校验和保存操作偏好。未来版本、损坏或不可读取的数据不被覆盖；保存失败时当前会话仍可使用选择，界面给出未保存提示。
- `combat-ui.js` 创建真实控件，`menu-ui.js` 移动原节点至操作分类，保留监听器；没有新增一套脱离状态模型的表单。
- `app.js` 仍使用原 ADS 插值、武器开镜门槛与射击逻辑，只替换输入意图的管理。
- 切枪、暂停、失焦、指针锁丢失、结束与重置会清理开镜状态。模式变化也清理旧的临时锁定，避免卡镜。
- 换弹期间仍按原规则暂时放下瞄准，点按模式的意图可以在装填后恢复。
- 电弧战刃的右键仍用于弹反；重锤右键不进入开镜。原 1/2/3 槽位、滚轮、按住左键连续近战、全类型25%补给及存档编号均不改动。
- 两份样式文件只补充新控件的布局；窄窗口使用同一操作分类。

## 验收

在原游戏页按 `Ctrl+F5`，进入「设置 → 操作 → 开镜方式」。

1. 选择「长按右键」，确认松开后退出开镜。
2. 选择「点按切换」，右键点击并松开，确认保持开镜；再点一次退出。
3. 刷新后检查选择仍保留；调整灵敏度后再次刷新，确认两项都正确保存。
4. 持刀检查右键弹反；切枪或暂停后确认不会卡在开镜状态。

入口：`http://localhost:5173/index.html?menu=settings&category=controls`。
