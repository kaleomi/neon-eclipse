# NEON ECLIPSE｜固定翼飞机、游艇与海陆空联合试验区

日期：2026-09-17

## 本轮交付

按用户确认，新增固定翼飞机和游艇，并与已有越野车放入同一个联合试验区。没有重新打包 EXE，也没有更改六章战役、星星、挑战解锁或存档格式。

进入：主菜单 → 选择关卡 → 海陆空先遣 / 载具试验。原服务仍使用 `/vehicle.html`。

## 场景与载具

- 试验区扩大为 1200 × 1200 米的静态场景，包含原越野环线、连接道路、西侧机场、760 米跑道、东侧海岸水域和游艇码头。
- 越野车可驶往机场或码头附近；车辆不会驶入水域。步行只允许陆地及码头/栈桥表面，未加入游泳。
- 单座固定翼飞机具备油门、地面滑跑、抬头起飞、俯仰、滚转、方向舵、失速下降、正常降落、硬着陆/落水/障碍碰撞受损与回收。
- 游艇具备前进、倒车、舵向、惯性减速、反推减速、岸线/码头/岛屿碰撞、靠泊上下船、波浪摇摆和尾流表现。
- 三类载具都有追尾与前向视角。步行靠近可用载具按 E 进入；上下载具会清空旧输入，避免把上一种载具的按键带入下一种。
- 飞机空中或滑跑未停稳不能离机，受损后需回收。游艇必须停稳且存在可落脚的码头/栈桥位置才能下船，不能跳入开放水域。
- 三条独立路线：越野六点、飞行五个三维导航门、海上五个浮标点。飞行路线使用三维距离，不把地面经过导航点当作飞行完成；海上路线最后一点为靠泊引导，完成后仍需自行驶近泊位。
- 飞机 HUD 增加高度、油门、升降率、安全降落计数及失速/高度上限提示；小地图标记陆/空/海三台载具。

## 操作

通用：E 上下载具；C 切换视角；Esc 暂停；鼠标观察或左键拖动观察。鼠标不直接控制飞机姿态。

### 飞机

- Shift 增加油门，Ctrl 减小油门。
- S 抬高机头，W 压低机头；A/D 滚转，地面时用于滑行转向。
- Q/Z 方向舵；空格仅在地面刹车，不是空中瞬停。
- 起飞：沿跑道提高油门，速度超过约 101 km/h 后抬头。
- 巡航建议 25–40% 油门，转弯前预留空间；场地边界有限，满油门不适合持续绕小场地飞行。
- 正常落地条件：平坦陆地、速度不高于 48 m/s、下降率不超过 6 m/s、滚转/俯仰处于容许范围。建议始终使用跑道起降。
- 高度上限约 300 米；触及边界或撞到障碍会中止试验，需要回收。

### 游艇

- W 前进，S 减速后倒车；A/D 转舵，静止时不会原地旋转。
- 空格使用反推减速，不是陆地手刹。
- 最大前进速度 13 m/s，倒车不超过 4 m/s。
- 靠近码头、速度降至 0.6 m/s 以下并有安全落脚点后，按 E 下船。

## 试验调度与状态保护

暂停菜单的“车库／机场／码头”是显式试验调度，不是普通地图旅行。按钮需要二次确认，会回收三台载具并重置全部试验路线，再将步行角色放到对应地点。可用于快速测试，也可在飞机受损后恢复。

停稳后按住 R 可回收当前试验；飞行中禁止直接快速回收，需通过暂停菜单明确调度。页面失焦、隐藏或暂停均冻结载具、海面动画和路线计时，并清空输入。

试验区不保存位置、路线或载具状态；退出、刷新、调度均会重置。原六章结果待保存时仍拒绝从菜单跳转到试验区。暂停中的原战斗离开前仍提示挑战资格与阶段入口恢复的影响。

## 代码与边界

新增：

- `flight-rules.js`：独立固定翼控制、起降/失速/碰撞/离机规则与飞行导航数据。
- `maritime-rules.js`：海岸、码头、陆水表面、游艇控制、上下船、三维/二维路线检测。
- `sea-air-world.js`：机场、海岸水面、码头、飞机与游艇模型、导航标识。
- `test-sea-air.mjs`、`test-sea-air-browser.mjs`：规则及浏览器交互回归。

更新 `vehicle-app.js` 统一调度三类载具；`vehicle-world.js` 增加扩展场景选项，保留原越野模块调用兼容；选关入口、HTML、CSS 和测试命令同步更新。

这是简化单人海陆空原型，不是完整飞行或航海模拟器：无真实空气动力学、四轮/起落架悬挂、气象系统、潮汐、燃油、武器、多乘员或联机。飞机粗糙地形滑行没有专门悬挂模型，建议在跑道起降。游艇波浪摇摆主要为表现层，不是流体浮力解算。飞机有受损/回收状态，不是可维修的完整部位伤害系统。

场景全部静态加载，尚无区块流式加载、浮动原点或开放世界任务系统；扩大场地不等于已经完成大地图架构。目标为桌面键鼠，窄屏布局不代表已支持手机触控驾驶。此前 EXE 不含本轮内容。

## 复跑

```bash
npm run test:vehicle
npm run test:sea-air
```

可选浏览器测试需另备 Playwright 与 Chromium；本轮未在 Windows 原项目安装这些依赖。脚本默认连接 `http://127.0.0.1:5173/vehicle.html`，支持 `VEHICLE_TEST_URL`、`VEHICLE_PLAYWRIGHT_MODULE` 和 `VEHICLE_SCREENSHOT_DIR`。测试使用新的浏览器上下文，不应指定用户真实浏览器资料目录。

```bash
node test-sea-air-browser.mjs
node test-vehicle-browser.mjs
```
