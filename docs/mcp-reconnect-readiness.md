## 使用规则

- 以远端最新源码为准，先发现/搜索/读取，再用版本保护的小补丁编辑；不把旧浏览器镜像覆盖回项目。
- 独立读取可并行，每个 JSON-RPC 请求使用不同 ID；同一文件写入串行。版本过期时重新读取。
- 符号导航使用 LSP，精确文本使用搜索；空 LSP 结果不是不存在的证明。
- 命令显式指定 cwd，遵循 Windows 主机提供的 PortableGit Bash；只检查/停止本次自行启动的进程。
- 多步骤工作维护完整任务清单，最多一项进行中；代码修改后运行诊断、相关专项和现有分层回归。
- 浏览器测试使用隔离上下文，不清除真实玩家数据；不改未授权的存档格式、既有成就或其他协作者改动。
- 开发总结落在 docs/mcp-*.md，使用 LF 和仓库路径，测试日志/探针留在 docs 之外。
