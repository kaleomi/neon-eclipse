# MCP P1 第五批：RAILSPIKE 蓄力磁轨手枪

## 交付范围

主线 FPS 源码已接入，第七运行时槽、按键 7；原有 1–6 不变。本批实现开发计划 5.2 的单发磁轨手枪、0.8 秒蓄力、三个目标穿透和明确薄板穿透。未制作 EXE，未引入最终携带限制或改装系统。

### 操作与数值

- 弹匣 1 / 备用 18；基础伤害 90，头部倍率 1.75；射程 90，55 起衰减，最低 70%；换弹 1.9 秒、发射冷却 0.55 秒；弹药补给增加 6，备用上限 18。
- 按住左键累积 0.8 秒后自动发射，持续按住仅一发，不循环蓄力。提前松开取消、不扣弹。
- R、切枪、暂停、重置、阶段完成、死亡/结算取消蓄力。暂停不会保存半成品蓄力；恢复后需要重新按住。R 在满单发弹匣时也可取消蓄力，不会白扣备用弹药。
- 仅实际发射扣弹并计一次统计；准备状态变化不储存蓄力。空弹匣可 R 装填，也可释放后再按左键触发装填；没有备用不会发射或补弹。
- 独立双轨/四线圈/电容弹匣模型，蓄力线圈增亮，复用枪机与装填动作；短蓄力提示脉冲、专用磁轨发射声、暖色弹道、第七 HUD 卡及蓄力进度条。
- 修正通用弹药提示：满装的单发弹匣不再误报“弹药不足”；真正空弹匣/缺弹提示保持。

### 穿透判定

`weapons/railspike-rules.js` 使用按距离排序的实际射线交点，按目标身份去重，同一敌人的多块模型/重复三角面只计一次。每发在发射瞬间重新取瞄准和 LOS，不锁定蓄力开始时的目标。

最多三个目标，伤害系数依次为 1、0.75、0.5625；仍按距离、命中部位、原有装甲和 HALO 标记结算。第四个目标不受伤。实体墙及未知世界几何默认阻挡；监察者任何核心/护盾/节点装置都终止射线，不借穿透绕过护盾，监察者生命值/节点数值未改。

只有显式 `railThin: true` 且 `railThickness` 在 (0, 0.25] 的薄板允许穿透；每发最多两块，每块令后续伤害再乘 0.85。多次与同一块薄板相交不重复消耗预算。第三块仍阻挡，不是无限穿墙。

真实场景在反应堆入口两侧增加两块铜色三条纹薄板：x ±5、z 24，尺寸 2.4 × 1.8 × 0.12，有玩家/敌人碰撞和普通 LOS 阻挡。仅此两块明确布置，未把六章薄墙、地板、星星路线或港口设施批量改成可穿透材料。中间通道保持畅通。
