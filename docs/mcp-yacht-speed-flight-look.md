固定步长控制器测试测得：0–100 km/h 约 4.09 秒，最高速反推停车约 2.26 秒、33.8 米。这是游戏模拟时间和位置数据，不是真实游艇性能、浏览器帧率或实机试玩测量。

保持停稳后才能下船、仅可在安全码头落脚，以及岸线、码头和岛屿碰撞保护。新增最高速/大帧间隔碰撞测试。

## 飞机

- 鼠标向左观察 → 记录左侧目标航向 → 飞机持续左转。
- 鼠标向右观察 → 记录右侧目标航向 → 飞机持续右转。
- 停止移动鼠标后仍会继续对准目标；机头对准后自动回中，不会因为镜头偏角未消除而无限转圈。
- 目标保存为世界航向，而不是每帧把当前镜头偏角重新叠加到机头。飞机转动时消费相对视线误差，所以镜头方向保持稳定。
- 自动协调滚转和方向舵，并在接近目标时抵消残余倾斜产生的转向，减少左右摆动。
- 水平偏角沿用约 ±77° 的观察范围，角度跨越 ±180° 时取最短转向路径。
- A/D 与 Q/Z 手动输入优先，结束手动控制后以当前航向重新对正，避免鼠标与键盘相互拉扯。
- W/S 仍负责压低/抬高机头；鼠标纵向移动只改变观察角度，不自动爬升或俯冲。
- Shift/Ctrl 油门、地面空格刹车、起降/失速/碰撞/禁止空中离机等规则保留。
- 点击场景锁定鼠标，或按住左键拖动观察，均使用同一视线引导逻辑。切换视角、上下机、回收时重新建立中立目标；暂停冻结航向。

飞机仪表增加视线偏差方向/角度，以及“已对准，自动回中”提示。

## 实现

- `flight-heading.js`：纯航向处理与自动转向控制；无 DOM 或渲染依赖。
- `flight-rules.js`：可选目标航向输入，保留旧的手动滚转/方向舵调用兼容性。
- `maritime-rules.js`：集中定义 `YACHT` 动力参数、高速舵角限制和水阻。
- `vehicle-app.js`、`vehicle.html`、`vehicle.css`：鼠标世界航向、输入优先级、提示及量程。
- `sea-air-world.js`：随航速增长的尾流表现。
- `test-handling.mjs`、`test-handling-browser.mjs`：专项回归。
- 更新海陆空测试中的速度上限和驶离泊位条件，避免提速后旧测试在仍可安全下船的泊位内误判为开放水域。
