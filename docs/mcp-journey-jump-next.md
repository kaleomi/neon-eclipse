# 连续战役与空格跳跃：本轮交付及后续方案

## 本轮范围

按“分阶段推进整份路线图”的选择，完成第 1 阶段：三章连续战役、独立战役存档、章间过渡，以及空格跳跃。本轮没有同时实现专属 Boss、写实渲染、移动列车或多层敌人寻路。

## 如何体验

打开 `http://localhost:5173` 并 Ctrl+F5 刷新：

- 点“开始三章战役”，进入战役页面后点“进入当前战役章节”。
- 已有战役时可点“继续战役”。重开战役需要再次确认，避免误覆盖。
- 章节完成后点“继续下一章”，可立即进入下一章，也可选“稍后继续”。在章间退出或刷新不会丢失已经保存的章节结算。
- 顶部地图卡片进入原来的单章模式，原检查点和阶段训练仍可使用。
- 游戏中按 **Space** 跳跃；WASD 移动、Shift 冲刺、鼠标射击、R 装填、E 交互、Esc 暂停保持不变。

## 已实现的战役规则

顺序为反应堆设施 → 地下运输站 → 天穹通讯枢纽。完成最终撤离条件后才记录该章完成，不是击杀最后一个敌人就提前跳章。

- 使用新键 `neon-eclipse.journey.v1` 保存战役。三个原有单章存档键不写入、不覆盖。
- 保存当前章节、阶段入口检查点与已完成章节的结果。
- 检查点保留生命、弹药、武器、已用补给、朝向与站立高度。旧检查点没有高度字段时按地面入口读取。
- 每章开头重新整备生命和弹药；章内仍沿用现有资源管理，没有每阶段免费补满。
- 失败可从战役检查点重试；章节过渡以列车/升降平台示意图和原创字幕衔接，没有强制等待。
- 三章结束会显示完整战役结算。记录用时沿用检查点计时，重试前未保存的时间不会累加为排名成绩。
- 浏览器无法写入战役存档时会提示，并阻止直接跨章跳转。当前页面和站点存储仍是唯一存档来源，不提供跨浏览器同步。

## 已实现的跳跃规则

- 单次起跳，重力下落，高度约 1.4 米；长按不会自动连续跳，空中再按也不能二段跳。
- 可以落在低矮掩体或终端顶面，走出支撑面会落下。
- 检查玩家身体高度、侧面碰撞和头顶结构；在车厢低顶下会碰头回落。
- 使用小步长积分，降低穿过薄门、薄顶的风险。地图外缘保持保护，不能靠跳跃离开屋顶。
- 空中可以射击或装填。普通终端交互必须落地站稳；已经启动的范围上传仍可边跳边防守。
- 第三章的地面放电在玩家脚部高度低于 0.35 米时才造成伤害。起跳不会暂停危险区域的计时。
- Esc 和窗口失焦会冻结垂直运动，继续后沿原状态落下；重置阶段会清理残留起跳输入。

当前是玩家的高度碰撞与跳跃系统，碰撞以盒体近似为主。尚无摔落伤害、蹲伏/攀爬、移动平台承载，也没有给敌人加入跨层跳跃寻路。

## 验证

新增纯逻辑测试覆盖起跳、最高点、落地、低掩体支撑、头顶碰撞、门阻挡、屋顶边界、暂停、地面放电、三章状态推进、章节间存档、旧存档隔离和存储失败处理。

本地 Chromium 受控测试验证：真实 Space 输入、长按不连跳、空中暂停、阶段刷新、死亡重试、站立高度恢复、车厢碰头、完整三章推进、章间稍后继续、最终结算，以及原单章检查点仍能读取。页面 JavaScript 异常为 0。

测试使用受控清敌与时间推进，不是完整人工战斗通关。跳跃后掩体优势、跳跃躲弹难度、三章补给平衡和真机帧率仍需试玩。

# 后续开发方案

## 第 2 阶段：第三章专属 Boss（下一轮优先）

暂定“枢纽监察者”，重点是不同打法，不是复制 Warden 加血。

- 电弧扫射：明确预警、可横移或跳跃躲避的攻击窗口。
- 可破坏供电节点：玩家主动切换目标，切断供电后制造核心暴露机会。
- 与屋顶危险区域联动，但必须保留安全路线，避免不可躲伤害组合。
- 阶段转换、核心命中与攻击方向反馈使用现有全息 HUD，不往底部加重复信息。

验收：能看懂预警、能主动制造输出窗口；死亡、暂停、读档和切阶段时没有残留攻击；武器与补给足够支持完整战斗。

## 第 3 阶段：动作、画面与性能精修

- 强化逐发装填的手部动作、枪械机械运动，以及近战蓄势、挥砍、收势和命中时机。
- 精修三章材质、局部布景和环境音，减少重复的方块外观。
- 加入可关闭的适度泛光、改善局部照明；真实反射先评估成本。
- 在用户机器上记录帧时间，再确定灯光、粒子、后处理和画质档位预算，不用软件渲染截图的 FPS 代替实机测试。

验收：动作与实际装填/伤害同步；降低画质不丢关键战斗提示；UI 保持清晰，瞄准区域不被遮挡。

## 第 4 阶段：真正的高低差与载具场景

- 楼梯、上下层通道和可乘坐升降平台。
- 移动平台上的玩家承载与碰撞处理。
- 敌人跨层寻路、从不同高度攻击玩家。
- 再考虑列车实际行驶及第四章，而不是先画出平台却没有可用的高度逻辑。

验收：上下层均可到达、敌人不会卡层、移动平台不把玩家挤进墙里，存档能恢复正确支撑面。

## 每阶段都做的事

完整试玩三章，记录死亡位置、通关用时、弹药余量和帧时间；保留旧存档兼容、单章训练和回归测试。优先解决影响通关和手感的问题，再扩大内容数量。
