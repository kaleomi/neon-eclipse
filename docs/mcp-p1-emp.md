# P1 第十一批：EMP 投掷物首批

日期：2026-09-18

## 用户确认

无伤害 EMP 不影响纯刀资格；开枪或死亡仍按既有严格单章一命规则失去资格，检查点重试也不恢复失败资格。

## 当前实现

- 按住 G 预览轨迹与球形爆发范围，松开 G 投掷；切换武器、换弹、开火或暂停取消未投出的预览。
- 每章／全新训练入口 2 枚，同时最多一枚飞行中；本批不从弹药补给中补充。消耗记录沿用现有检查点回滚语义，而非每次投掷强制写盘。
- 1.2 秒引信、6 米真实三维球形范围、3 秒失能，无生命伤害、无武器射击计数、无纯刀违规调用。
- 仅 `sentry`、`swarmDrone`、旧 `drone` 可失能。Boss、工程兵、其他守卫与 Boss 装置不受影响。
- 弹体采用分步抛物线与连续中心射线碰撞，碰撞后停留直到引信结束；发射偏移也经过碰撞检查，不通过薄墙偷放。可在空中爆发，并非始终在地面炸开。
- 爆发需要到敌人战斗锚点的无遮挡视线；预览球表示最大半径，不是穿墙有效区。已有实体掩体阻隔失能。
- 取消受影响敌人的待发攻击，不删除已经发出的弹丸。失能期间不移动、不新开火；恢复后仍需新的攻击预警。
- 被 EMP 击中的编队无人机脱离原编队，恢复后从原地重新接敌，避免瞬移追上移动中的旧队列；仍共用原蜂群攻击预算。失能的照明源清除其共享情报，接收者自己的视觉记忆保持原规则。
- 新 HUD 提示余量、G 操作、引信与无伤害规则；目标面板显示失能倒计时。炮塔失能时关闭扫描扇区并调暗核心。
- 检查点新增可选 `emp: {charges: 0..2}`；旧存档缺字段默认 2，合法零值保留，非法数量拒绝存档。连续战役复用原检查点校验，不更换旧键或清除已有数据。暂停、结束、重置和阶段切换清理规则已接入。
