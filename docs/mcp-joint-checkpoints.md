# 海空接力｜安全检查点交付与下一步

日期：2026-09-17

## 本轮结果

安全检查点已经接入原项目。玩家完成指定安全阶段后会自动保存，刷新或失败后可在菜单选择“从已保存节点继续”。恢复不是回到危险瞬间，而是重建预设的安全停放状态。

**只更新源码，没有制作 EXE。** 旧便携版不包含本轮内容。

## 三个自动保存节点

| 保存时机 | 恢复后的起点 |
| --- | --- |
| 步行领取设备完成 | 从车库继续，设备已领取，下一步驾车去码头 |
| 海上交付完成、返港并安全下船 | 从码头继续，下一步回到越野车并驶往机场 |
| 越野车抵达机场停车区并停稳 | 从机场登机前继续，不必重跑陆海阶段 |

只保留最近一个节点，不是多存档槽。飞行中、碰撞瞬间、地面上传中和最终交接阶段不产生新的检查点。

## 使用方式

1. 正常进行“海空接力”，完成上述阶段后等待保存提示。
2. 飞行失败或需要退出时，可打开暂停菜单查看“海空接力 · 安全检查点”。
3. 点击“从已保存节点继续”，确认后恢复；刷新页面后也可使用同一入口。
4. 保存失败时，留在当前页面处理空间或权限问题，再点“重试未完成的保存操作”。

开始新任务不会立即删除旧节点；到达新任务的安全节点且提交成功后才替换。切换单项任务、回收或试验调度仍会中止当前联合流程，但不删除已成功保存的检查点。

## 恢复时重建什么

- 玩家回到安全步行位置，越野车、游艇和飞机回到对应节点的预设泊位。
- 所有载具速度归零，飞机油门、受损状态和本次落地次数重置。
- 当前输入、视角偏移、临时路线和单项任务状态清理。
- 重建已完成阶段前缀，不还原未完成的保持进度。
- 新建运行 ID，清空旧飞行尝试 ID；重新登机时生成新的飞行尝试。
- 显示“检查点继续”。计时从保存节点继续，不表示完整一命通关用时。

恢复坐标和速度不从存档读取。即使记录里附带其他位置字段，也不会用来把载具放到半空、海底或障碍内部。

本轮联合任务仍不写入归航/侦察单项成绩，也未增加联合排行榜。

## 存储与保护

独立 IndexedDB 数据库：`neon-eclipse.joint-checkpoint.v1`，数据库版本 1，`checkpoint` 仓库。检查点规则标识为 `joint-v1`。与六章战役、星星、成就和单项飞行成绩隔离。

- 只有事务提交完成才报告成功，不把单次写入请求成功当成整个事务完成。
- 使用修订号比较，阻止旧页面静默覆盖另一页面的新节点。
- 同一操作可以去重重试；不同内容或不同页面发生冲突时提示处理。
- 读取、确认恢复之后才采用该节点的写入修订号；取消恢复不会偷偷接管另一页面的版本，也不会丢弃本页待保存操作。
- 损坏数据、不兼容版本或异常结构不会被自动覆盖，界面显示“状态未知”，而不是零存档。
- 保存失败时保留以前已提交的节点，并提供本页重试。
- 支持跨页面通知、窗口聚焦刷新和手动读取。
- 联合任务完成后关闭本次保存/恢复链所属的检查点。若另一页面已经更新，则保留对方的数据并提示冲突；未能关闭旧节点时明确显示失败。

## 当前限制

- 这是当前浏览器来源下的本地检查点，不是云存档；不同域名、端口、浏览器或设备不自动共享。
- 强制关闭、崩溃或确认离开后，尚未提交的操作可能丢失。离开提示不能替代崩溃恢复。
- 暂无多存档槽、手动回滚到更早节点、导入导出或损坏数据修复界面。
- 清理站点数据会删除本地检查点。
