## 二、HUD 与补给包已经修改

### 1. 弹药与生命数值

- 弹药面板左侧改为横排三枚子弹图标，不再是一枚细长竖向图标。
- 当前弹药、备用弹药和生命数字统一采用粗重、斜切、描边和硬阴影的艺术字表现。
- 继续显示真实数值；没有用图片覆盖或伪造弹药/生命。零弹药、满血、低血量、近战 `∞ / —` 均保留。
- 横排三枚子弹是弹药识别图标，不代表只剩三发；实际剩余量由右侧数字表达。
- 近战时图标降低亮度，文字继续标明“近战”；低血量数字有对应强调。
- 保留 HUD 跟随和缩放，窄屏限制会造成左右读数相撞的放大效果。
- 字体使用系统粗黑字形回退与 CSS 样式，不依赖外部字体网络服务。

### 2. 医疗与弹药补给

- 医疗补给使用浅色箱体和红色加号，在顶面、正面及箱体上方都可辨认。
- 弹药补给的顶面、正面和上方使用与 HUD 同源的横排子弹图形。
- 上方图标面向相机；保留场景深度测试，不开启透墙显示。
- HUD SVG 与场景图标共用轮廓定义，避免两处逐渐变成不同样式。
- 补给位置、拾取半径、楼层判定、满血/满弹时的拒绝消耗，以及重试/读档恢复规则不变。

实际截图检查中发现半透明底板会压暗图标，已调整透明绘制层次，并增加像素亮度检查。最终医疗加号呈清晰红色，弹药图形呈金色。

主要文件：`supply-symbols.js`、`supply-badge.js`、`hologram-ui.js`、`hud-counter-art.css`、`mission-world.js`、`index.html`。

## 三、近战第一轮实现

### 保留的参数

| 参数 | 本轮结果 |
| --- | --- |
| 刀具基础伤害 | 保持 95 |
| 攻击距离 | 保持 3.5 米，以实际命中表面距离计算 |
| 攻击间隔 | 保持 0.45 秒 |
| 接触时机 | 保持出刀后约 0.19 秒 |
| 单次命中目标数 | 最多 1 个，不改成范围多杀 |
| 枢纽监察者血量 | 保持 1920；原节点、护盾与暴露规则保留 |

### 新判定方式

- 从单条准星射线改为命中帧的有限扇形采样：水平 ±18°、垂直 ±7°，共 21 条采样射线。
- 中心射线命中时优先保留中心对象及其部位；不会为了弱点倍率自动选择旁边的核心。
- 中心未命中有效目标时才使用边缘补偿；相同角度优先较近接触。
- 每条候选路径检查场景遮挡及有高度的实体体积，不能靠边缘采样穿墙。
- 对真正贴身、相机落在目标局部包围盒中的情况，使用不参与渲染的双面代理检查实际三角面，避免背面剔除导致近距离漏判；不修改敌人的可见材质。
- 原有暂停冻结、切枪取消待发近战、跨接触时间只触发一次的规则保留。
- 枪械射线、霰弹颗粒、伤害衰减和爆头分支仍走原逻辑。

这是受限的接触采样，并非真实刀刃在整个动画过程中连续扫过的物理模拟。它已通过代码与受控交互回归，但尚不能据此宣称真人纯刀打通全部六章。

主要文件：`melee-sweep.js`、`app.js`；保留 `combat.js` 和 `action-poses.js` 的原伤害与时序参数。
