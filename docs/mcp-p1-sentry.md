## 已实现

- 专属双管炮塔、圆形底座、背部绿色核心。底座使用保守的 1.2×1.2 AABB，与旋转无关；击杀和重置时移除其碰撞并刷新导航。
- 绿色扫描扇区：22 米最大射程，左右各约 18°；扫描相对初始朝向摆动 ±0.9 rad，周期 12 秒，不进行全向追踪。1.6 米内留出炮口近距盲区。扇区按炮口高度的障碍射线裁剪，不代表所有高度的精确可见域。
- 自身视线通过才锁定，完整 1.2 秒预警，捕获旧目标点；之后三发按 −0.09 / 0 / +0.09 rad 扫过，每发间隔 0.18 秒。横移和实体掩体可用于规避。
- HP 150，正面身体承受 35% 伤害，侧后身体正常，背部绿核两倍。装饰扇区和轮廓线不参与武器命中。
- 接入现有攻击调度：炮塔独占其三发扫射，与蜂群／协作小组的新攻击互斥。不是把三发炮弹宣称为旧小组的两发物理弹上限；普通守卫保留原有预算逻辑。
- 击杀取消未发出的弹幕；已经发出的弹丸沿用既有系统继续飞行。结束／重置清理弹幕。检查点不新增序列化字段，严格单章纯刀资格不被重试恢复，弹药不返还。
