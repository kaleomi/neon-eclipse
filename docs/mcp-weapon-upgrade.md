# 武器轮廓、逐发装填与近战动作

## 视觉
- 武器栏的四个色块图标替换为独立内嵌 SVG：步枪、管式弹仓霰弹枪、消音手枪、能量短刃。
- 第一人称模型独立在 weapon-models.js，增加倒角机匣、圆柱枪管与枪口、护木、导轨、瞄具、弹匣、扳机护圈、枪托、侧挂霰弹与识别铭牌。
- 增加圆润手套、手指和袖口；霰弹装填时左手向装填口移动，单颗弹壳上移入枪。
- 近战改为宽刃而非细长三角锥，0.42 秒横斩和收回，手臂随武器移动。伤害仍按开火时的准星射线判定，距离 3.5 米；不是全屏范围攻击，也不是骨骼动作捕捉。
- 模型和图标均为本地程序化资源，没有外部贴图或 CDN 依赖。旧 art.js 的 createWeapons 保留但不再使用。

## 霰弹枪
- 从 0.78 秒半自动改为 0.32 秒射击间隔，可连续点击或按住左键连射。
- 管式弹仓容量仍为 8，备用上限仍为 48。每 0.55 秒实际装入一发，而不是动画结束一次性补满。
- 弹仓里有弹时开火会取消当前装填，马上射击（仍遵守射击间隔）。已装好的弹保留，未完成的那一发不会扣备用弹药。
- 空仓按住开火时，装入第一发后即可射击，支持装一发打一发。切枪中断也不会吞掉已经装好的弹药。
- 填满、备用耗尽自动结束；Esc 暂停冻结装填。步枪和手枪继续整弹匣换弹。
- 显示“逐发装填 当前 / 容量 · 左键开火中断”。伤害、散布和衰减未改；更快射速后的整体难度尚需实机平衡。

## 验证
npm test 包含六组逻辑测试及模块语法检查。新增测试覆盖逐发时间、装填上限、备用耗尽、中断保留、整弹匣换弹不受影响，以及近战大幅位移和恢复。

Chromium 受控测试验证：0.3 秒不提前装弹、0.55 秒一发入仓、该发可以立即射出并取消装填、1.1 秒内射击 4 发、切枪保留已装弹、暂停冻结、近战横移/旋转并回到待机、四个 SVG 图标。页面异常为 0。原有枪械、五阶段任务及敌人/Boss 回归通过。

这不是完整人工通关或 Windows 真机性能测试。实际操作请 Ctrl+F5 刷新 http://localhost:5173，2 切换霰弹枪、R 装填，4 切换近战后点左键。
