## 原因与最小修复

`vehicle-weapons-world.js` 的炮管沿模型局部 **-Z** 指向前方。正的 X 轴旋转应使该方向的 Y 分量上升，但原模型更新使用 `pitchGroup.rotation.x=-weapon.aimPitch`，与规则的正俯仰含义相反。

射击规则 `aimDirection(yaw,pitch)` 的垂直分量为 `sin(pitch)`，实际射击与炮手摄像机使用该方向。本轮隔离测试确认向下/向上射击原本能命中相应测试目标；错误在炮管显示，不是把鼠标和弹道一起倒置。

本次仅将模型俯仰改为 `pitchGroup.rotation.x=weapon.aimPitch`，附坐标说明。不改鼠标设置、相机、武器数值、俯仰限位、散布、判定枪口位置或存档；不修改 FPS 入口、直升机及并行 Boss 工作。

## 验证

新增 `test-turret-pitch.mjs`，调用真实模型和射击规则：

1. 既有向下/向上射击命中正确方向的目标。
2. 向下瞄准时渲染炮口下降。
3. 向上瞄准时渲染炮口上升。
4. 水平瞄准在车身转向后仍保留正确世界朝向。
5. 四种车身朝向、三种瞄准朝向、四档俯仰（含上下限）的 48 个组合中，模型炮管轴与无随机偏移的实际射击方向一致。
