# 高难度隐藏星星区域：第一、二、四章

## 已实现

按用户选择的 hard 难度重做三颗星星的取得路线，第三章高架星星保持不变。三个新增空间都是可选探索，不属于主线门禁条件。

### 第一章：窄平台跑酷

西侧边缘新增九座交错窄平台，宽/深 1.25 米，沿路线逐级增高至约 6.4 米。平台中心纵向间隔 3.3 米；玩家需要使用已有跳跃控制，并在空中修正落点。星星位于最后平台。平台不是自动爬升台阶，不修改原有跳跃、重力或视角输入。失败落到普通地面，可返回起点再试，没有新增死亡坑。

### 第二章：墙后暗室

东侧增设与场景同色的假墙和封闭暗室。北侧约 1.4 米窄入口只留小型通风标识，内部另设挡墙，需走到远端绕过再返回星星所在夹道。星星不能从假墙外贴墙直接拾取；墙体接到既有顶棚，不能跳过顶端。原调度主线、敌人刷怪与补给保持可用。

### 第四章：塔底迷宫

在 3 米设备层的楼板下设置 18×18 米、5×5 格固定迷宫，脚下仍是大厅的 0 米地面，不是新增负高度地下层。共六处死胡同，入口到星星的唯一解经过 17 格。西侧服务窄口宽约 1.3 米；隔墙顶接楼板，不能跳墙抄近路。少量旧阀门编号辅助辨识，但不提供正确路线箭头。可沿路返回，主线可从外侧绕开迷宫。

## 实现与兼容

- `hidden-data.js`：可选区域统一几何数据、跑酷平台、暗室路径、固定种子迷宫拓扑及新星星坐标。
- `hidden-world.js`：实体场景与碰撞、少量环境标识、局部照明。
- `collectibles.js`：将第一、二、四章星星迁往新位置。
- `app.js`：创建可选区域后再构建导航和玩家碰撞。
- `radar.js`：隐藏区域隔墙不显示在雷达上，避免直接泄露迷宫布局。
- `test-hidden-stars.mjs`：真实玩家物理执行跑酷、暗室往返、迷宫往返及楼层判定。

星星存档键和四颗解锁成就规则没有改变。已经取得的星星/成就保留，不会为了新布局强制清空记录；已收集的星星也不会自动重生。旧检查点若与新增实体碰撞，原有安全恢复逻辑会回到对应阶段入口，保留生命、弹药等检查点数据。
