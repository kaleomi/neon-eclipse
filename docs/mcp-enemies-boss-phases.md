# 混合敌人与 Warden 阶段战

## 本轮范围

不扩大地图，保留五阶段任务、补给和撤离条件。各任务阶段改为固定数量的混合小队；Boss 总生命仍为 1000，不以单纯加血延长战斗。新模型和材质均为本地程序化资源。

## 三种守卫

| 类型 | 识别与行为 | 攻击与应对 |
| --- | --- | --- |
| 突击 | 橙色、短枪；快速逼近到约 5.5 米 | 0.45 秒预警、两发近角度弹；拉开距离或近距离使用霰弹枪 |
| 远程 | 紫色、长枪与天线；尝试保持 17–25 米，过近后退并横移 | 1 秒紫色瞄准线预警，单发高速弹；方向锁定于蓄能开始时的位置，横移或用掩体躲避 |
| 重装 | 金色、大型正面盾板、青色背部核心；慢速、转身速度受限 | 正面只承受基础结算伤害的 30%，侧后方无该层减伤，背部核心 ×2；0.9 秒预警后发射慢速三连扇形弹 |

上述伤害倍率在武器距离衰减/头部倍率之后结算。重装并非无敌。寻路继续使用共享流场，加入退让、横移、缓慢转向和轻量分离；移动仍经过地图碰撞。各阶段守卫总数仍为 5、6、7、4（Boss+3护卫）、4。

## Warden

阶段按生命比例推进，不会倒退：高于 67% 为 I，高于 34% 为 II，其余为 III。切换阶段有 1.2 秒提示期间，不移动或攻击；清理该 Boss 的旧预警及飞行弹丸，不清理护卫的弹丸。

| 阶段 | 攻击 | 过载窗口 |
| --- | --- | --- |
| I 精确压制 | 0.9 秒瞄准线预警后单发射击 | 两次攻击后暴露 3.4 秒 |
| II 扇形封锁 | 1 秒预警后五连扇形弹 | 三次攻击后暴露 3.2 秒 |
| III 交错扫射 | 0.8 秒预警后两轮三发交错弹，间隔 0.3 秒；移动稍快 | 两次攻击后暴露 3 秒 |

最后一轮弹丸完成发射后才开启过载。暴露期间 Boss 停止移动和射击，胸口核心变为青色，核心伤害 ×2.5；其他部位正常结算。非暴露期承受 55% 伤害，因此玩家始终可以造成伤害，不是强制无敌阶段。护卫仍会威胁玩家。所有弹丸保留扫掠碰撞、掩体阻挡、固定目标位置和容量上限。

## 反馈与模块

- enemy-rules.js：敌人参数、小队编排、装甲结算、转向与 Boss 纯状态机。
- enemy-model.js：不同轮廓与颜色、装甲/核心命中区、简单摆腿和抬臂动作；不是骨骼动画或布娃娃系统。
- enemy-ai.js：战术移动、瞄准蓄能、错峰攻击和 Boss 调度。
- enemy-ui.js / enemies.css：准星目标名称、生命、打法提示、护甲/核心反馈、Boss 阶段和暴露倒计时。
- projectiles.js：按攻击配置支持颜色、速度、伤害、扇形、间隔连发、预警瞄准线及按攻击者清理弹丸。

调整了 Boss 核心亮度以减少过曝；准星已显示 Boss 信息时隐藏重复的任务目标标签，减少文字重叠。消失的预警线释放独立资源，敌人移除时释放自有几何和材质。

## 验证

新增 test-enemies.mjs，覆盖各阶段小队、战术决策、转向限速、正面/侧面/背部结算、Boss 阈值与阶段不倒退、完整发射后开启窗口、窗口倍率和关闭恢复。

独立 Chromium 受控测试通过：实际追击/后退/慢转、真实射线命中重装正面/侧面/背部核心（步枪示例 7.8 / 26 / 52 伤害）、各 Boss 攻击发射数 1 / 5 / 6、瞄准线不提前伤害、取消旧攻击、自然攻击周期后过载、真实核心射击 65 伤害、暴露变色、暂停冻结、两次阶段切换和重开清理。页面 JS 异常为 0。

原有任务五阶段、补给、交互中断、撤离与重置、开火方式、换弹、方向提示、敌方弹丸闪避和掩体阻挡回归通过。npm test 执行语法检查及四组纯逻辑测试。

浏览器测试使用受控玩家位置、敌人状态与时间推进，不代表完整人工通关或 Windows 性能测试。混合敌人后的弹药需求、难度及一局时长仍需实机试玩；卡顿可按 Q。已有服务时 Ctrl+F5 刷新 http://localhost:5173。
