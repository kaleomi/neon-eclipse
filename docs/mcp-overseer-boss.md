# 枢纽监察者：首版机制交付

## 范围与体验

在第三章“信号上传”阶段新增固定式枢纽监察者。刷新现有游戏页面，选择第三章并推进到上传阶段；已解锁时也可用该阶段训练。

- Boss 480 HP；两座金色节点各 65 HP。
- 护盾期间核心免疫伤害；破坏两个节点后暴露核心 8 秒，期间停止电弧。超时节点恢复，需要再次破坏。
- 电弧锁定玩家方向，黄色预警 1.5 秒后释放 0.55 秒，之后休止 2 秒。范围长 34 米、宽 2.8 米；每次最多造成 18 伤害。
- 横移出预警带、脚部跳到 0.65 米以上或利用实体掩体可躲避。预警锁定后不追踪玩家。
- Boss 存活时地面高压关闭，击败后重新从安全周期开始。
- 击败 Boss 并清理守卫后才可建立上传；原来的增援、20 秒范围防守和撤离流程保留。
- 右上提示显示生命、剩余节点、预警和暴露倒计时。

## 兼容与边界

保持五个阶段、已有存档键及检查点格式不变；不覆盖用户存档。重试或刷新从阶段入口重置 Boss，和该阶段守卫一致，不保存战斗中间状态。原有已经进入撤离阶段的存档不会强制回退补打 Boss。同阶段上传增援不会复活 Boss。

本版是固定式节点 Boss，不是最终美术，也不是连续旋转扫射。暂未接入雷达专属图标，没有跨层移动或新 Boss 动画。模型为独立几何体，不作为玩家实体障碍物。

## 文件

- `overseer-rules.js`：纯战斗状态、伤害和电弧判定。
- `overseer-world.js`：Three.js 模型、命中目标、预警带及提示。
- `app.js`：阶段激活、射击、伤害、暂停、重试和任务门控。
- `roof-world.js`：高压互斥；`roof-data.js`：阶段说明。
- `test-overseer.mjs`、`test-overseer-world.mjs`：规则及无渲染场景接入测试，均加入 `npm test`。

## 验证记录

修改前原测试全部通过。新增规则测试通过；Three.js 无渲染集成测试验证节点破坏、核心击杀、同阶段不复活、重试、预警平面与伤害方向一致、暂停和切阶段清理。集成检查发现并修正了预警带旋转方向问题。

本轮没有进行浏览器实际画面回归或人工战斗通关。DOM 在场景集成测试中使用最小替身，因此不代表 HUD 排版或真实输入已经验收。后续需试玩确认 HUD 可读性、实际射线命中、三章弹药平衡与帧率，并精修模型及攻击表现。
