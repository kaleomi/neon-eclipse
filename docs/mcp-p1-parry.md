## 操作与试点规则

刷新游戏，按 **4** 切换 ARC BLADE，按 **鼠标右键**。

| 项目 | 当前实现 |
| --- | --- |
| 窗口 | 0.25 秒模拟时间，按下启动；松开不会提前耗掉这次短窗口 |
| 动作周期 | 0.45 秒，复用原刀攻击节奏：0.25 秒窗口 + 0.20 秒恢复；不是无限连续防护 |
| 再次输入 | 必须松开后重新按下；按住不自动重开，重复点击不延长窗口 |
| 可反弹对象 | 普通、非 Boss、业务颜色标识为 orange 的弹体，入射方向位于视线正面半角 60° 的锥体内 |
| 不可反弹 | 紫、琥珀、粉、蓝、绿、未知标识、任何 Boss 弹、背后/侧后攻击；环境伤害也不受保护 |
| 接触时刻 | 使用原有玩家相对运动扫掠的实际碰撞比例；跨过窗口结束的帧不会整帧获得保护 |
| 返弹 | 原路反向飞行，保留原速度与基础伤害，不追踪、不吸附敌人，不重置原弹体寿命 |
| 返伤 | 普通敌人沿用当前难度出伤、护甲及 HALO 修正；不自动获得爆头/核心奖励 |
| Boss 边界 | Boss 演员及 Boss 装置会吸收返弹，不接入新的 Boss 伤害通道；屏幕明确提示需直接攻击 |
| 动作互斥 | 挥砍、切枪、刀攻击冷却期间不能起手弹反；弹反/恢复期间不能起手挥砍、冲刺或开始 EMP 预瞄；枪械右键 ADS 不变 |
| 生命周期 | 暂停或切枪取消尚未结束的窗口，但不刷新恢复时间；已反射的弹体随世界暂停/继续，切枪不改变其归属；死亡/结束/重置清空 |

窗口与周期是本批明确的试点规则，不将新增防御能力包装为“实战难度完全不变”。没有额外回血、全伤害无敌、伤害放大或敌人削弱；手感和挑战难度仍需人工体验及遥测评估。

## 碰撞、归属与反馈

- 普通弹与返弹都先比较实体墙接触，墙体与目标同时接触时由墙阻挡；去程和回程均不能穿墙。
- 返弹沿本帧真实路径对真实三角面做首命中检查；同帧碰撞后的剩余时间也继续推进，覆盖快速弹体。返弹中心扫线是伤害依据，发光外晕不扩大伤害体积。
- 使用非渲染双面代理，不修改敌人的活跃材质。隐藏祖先、脱离场景或已死亡目标不会成为幽灵命中对象。
- 每枚返弹只消耗一次；同一敌人被多枚返弹击杀也只计一次击杀。不将返弹显示为敌方雷达威胁。
- 击杀记入能量刀，即使返弹在途时切换到枪械也不变。弹反本身不消耗弹药、不增加枪械射击计数、不改遥测结构；纯刀条件保持原判断。随后实际开枪仍会使纯刀资格失效。
- 新增抬刀防御姿态、青色返弹、复用现有金属反馈声和全息提示条，显示窗口、恢复及失败原因。底部原生命/弹药布局未改。
- 已查看受控截图：移除镜头前的大块反射粒子，缩小返弹光晕；返弹拖尾最多 0.6 米，并且只沿已经走过的返程增长，不越过反射接触点穿入镜头。新增拖尾边界断言。
