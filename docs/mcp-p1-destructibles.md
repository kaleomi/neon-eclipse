# P1 可破坏物：反应堆薄板试点

日期：2026-09-18。用户接受弹反并授权下一步后实施。仅源码；不制作 EXE，不做 Git 提交。

## 交付与边界

- 将反应堆入口两块**既有**铜色磁轨薄板（x=±5、z=24）接入可复用耐久规则与碰撞生命周期。没有另加阻塞主路的物体，没有更改原 `rail-panels.js` 的尺寸、坐标或穿透标签。当前世界表现适配器仅面向这两块薄板，不声称爆炸桶/玻璃/全部章节已经通用化完成。
- 每块 60 耐久；八种武器含刀均可击碎。世界内显示耐久、分级裂纹、带高光切角的全息标牌；碎片池上限 20，0.65 秒回收，重试复用几何/材质/纹理，不持续新建。
- 摧毁时仅移除自己的障碍条目，更新导航；人物、普通射线、近战遮挡、敌方弹体、VOLT 视线均使用同一障碍数组。原结构墙和另一块薄板不受影响。
- 每颗霰弹重新取得碰撞目标：前面的弹丸击碎板后，同一发剩余弹丸可以进入缺口。RAIL 仍按该发开火时的接触顺序、最多两层薄板和原衰减处理，不因本发击碎就退还穿透损耗；后续射击才使用新缺口。
- 普通敌弹、Boss 弹体及已弹反的返回弹都可损伤隔板；敌弹使用既有 incomingDamage，返回弹使用 outgoingDamage。**击碎板的该颗弹体仍在板处消耗**，不会同帧穿板再伤人；下一颗才能通过。原 Boss 禁止弹反/禁止新增返伤规则不变，没有修改任何 Boss 模块。
- 隔板不是敌人：不加击杀、敌伤提示、任务进度、补给或掉落，不是 VOLT 链的来源，不叠 HALO 标记。枪击环境仍按实际开火取消纯刀资格；刀破板不取消，之后真实刀杀仍正常计数。EMP 没有新增破坏环境能力。
- 同一次游玩中保持破坏状态；重试、阶段重开或读档按初始布局复原，**不增加存档字段**。先移除试点板，再按既有逻辑校验保存位置；若玩家恢复在某块板内部或紧贴其原位置，该轮跳过恢复该板，避免读档夹人。其他合法保存位置和原有障碍校验不变。
- 暂停冻结破坏模拟及弹体；结束不继续产生伤害；重试清空碎片并重建安全布局。底部仅生命、右下弹药与既有全息 HUD 保留，世界任务目标未更改。
