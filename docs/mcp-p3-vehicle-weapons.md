# P3 第一批交付：车载武器、靶场与载具耐久

日期：2026-09-17
依据：`docs/mcp-full-development-plan.md` 第 7.2 节。P0 / P1 由其他 AI 负责，本批只接手 P3 载具域源码，不制作 EXE。

## 交付边界

**这是 P3 的第一批，不是整个 Phase 3 完成。** 直升机等新载具（7.3）、大地图流式（7.4）、先遣队战役线（7.5）均未开始。

本批完成：

- **越野车车顶机枪与炮手位**：车内按 F 切到炮手位，车辆保持当前速度直行 3 秒后滑行；鼠标瞄准（水平 360°，俯仰 -17°～+43°），左键射击，空格刹车，F 回驾驶位。炮手位不能直接下车。
- **飞机机炮 + 2 枚无制导火箭**：起飞后左键机炮、右键或 G 发射火箭。火箭有重力下坠、3.5 秒引信、14 米溅射；只在空中、未受损时可用。
- **靶场**：6 块地面靶板（场地北/东/南侧）、4 个气球靶与 6 架高空无人机（机场西北 -450,-400 一带，85 米高）、4 架低空无人机（绕场地中央 70 米半径盘旋，14 米高）。击破后按类型 9～14 秒重生。射线与火箭都被建筑/杆/地面遮挡。
- **载具耐久（越野车、游艇）**：撞击按撞前速度扣耐久（越野车 8～30、游艇 10～34）。60% 以下"冒烟"，油门与转向输入 ×0.8、最高速 ×0.8；25% 以下"失效"，只能 4 m/s 跛行且不能倒车。停回车库 / 码头泊位 / 机库，停稳 5 秒自动修复到 100%。
- **补给**：在同一泊位停稳 5 秒补满弹链（车顶 120 发 / 机炮 160 发）与火箭。弹链打空自动装填（2.4 s / 3 s）。
- **表现层**：车顶炮塔模型随瞄准转动、曳光线、火箭弹体、爆炸球、冒烟/失效烟雾、小地图靶标点；新增右上"车载武器 · 靶场"面板显示座位、弹链、火箭、耐久条、靶场统计与提示。

## 已知限制

- 车顶机枪只能打靶场靶标，没有敌方载具或 AI 反击（7.5 先遣队第 1 关的猎犬机伏击尚未实现）。
- 火箭对无人机为球体判定，没有近炸引信；高速侧向掠过可能擦边不炸。
- 炮手巡航只保持直行，不避障；撞墙同样扣耐久。
- 飞机不纳入三级耐久；游艇任务外的耐久与任务内 hull 是两套数字。
- 靶场统计不保存，不进成就/飞行成绩。
