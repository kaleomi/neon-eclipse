## 处决升级

- 九章均可持ARC BLADE按V，距离2.2m，必须低于15%生命且处于有限硬直，Boss及机械目标不纳入当前人形处决名单。重装、狙击、工程兵、指挥官、镇压者等非Boss人形已覆盖。
- 实际受伤进入低生命区间后，每个敌人一生一次1秒负伤硬直；仅设置低HP不赠送硬直，不产生永久定身。取消未射出的攻击，不消除已发弹丸。
- 动作0.6秒，0.3秒接触；前0.3秒保护，成功回复8HP，最高100。接触时重新检查活体、距离、遮挡；失手无回血。已接受目标保持有限硬直到动作结束。
- 敌方弹丸、Boss返回伤害、环境伤害及自伤爆炸均检查保护；不暂停Boss或环境模拟。切枪、暂停、死亡和重试结束保护；处决不伪造枪械开火，成功计入刀击破。
- 不更改视角输入、隐藏星、1920HP监察者或其他Boss血量。该批不是猎犬冲锋/机械处决生态重做。

## 改装工坊：本批为七把常规枪械

U携带终端展开改装工坊，VANGUARD、BREACHER、GHOST、TEMPEST、HALO、RAILSPIKE、VOLT各有枪口/弹匣/瞄具三个互斥槽。每槽原装加两种组件，不增加伤害或弹容量。

| 槽 | 解锁 | 组件与取舍 |
| --- | --- | --- |
| 枪口 | 任意1颗已保存星 | 制退器：后坐-20%、散布-10%、换弹+8%；精密枪口：散布-25%、后坐+12% |
| 弹匣 | 任意2颗已保存星 | 快装匣：换弹-18%、后坐+12%；配重匣：后坐-12%、换弹+8% |
| 瞄具 | 任意3颗已保存星或任一已保存单章挑战 | 反射瞄具：散布-8%、后坐+6%、ADS视野收缩24度；精确瞄具：ADS视野收缩34度、移动散布惩罚额外+0.2 |

- 解锁读取已有星星/荣誉记录，不重新授予或改写历史奖励；不能仅通过篡改选择框绕过保存时解锁校验。
- 显示本次生效配置与下次草案；保存仅影响本页下次章首新行动，不在进行中的战斗改属性、补弹或重置挑战。
- “应用并从章首重开”需要两次确认，明确丢弃当前行动进度，调用真实章首流程。仅继续游戏不会偷偷应用草案。
- 同枪选择正式组件后，不叠加旧T试点组件；轻量库存仍有效。不选择正式组件时，原T配置和旧存档继续工作。
- 新可选检查点字段 `weaponMods` v1保存8行三槽数据（近战行全0）。旧存档默认无正式组件、0弹药不恢复；未知高版本原样保留并禁用正式组件。更换/移除瞄具清理额外倍率及原本不存在的移动散布字段，防止属性残留。
- P4独立模式明确禁用本工坊，不覆盖并行开发的P4玩法参数。CINDER/LANCE/PULSE及近战不在本批改装范围。
- 当前没有消音隐匿、扩容弹匣或透烟热成像组件；原案中的这些是示例，不能将当前取舍组件说成已实现这些特殊能力。
