# NEON ECLIPSE｜越野车与荒原驾驶试验区

日期：2026-09-17

## 本轮范围

用户选择：地面越野车、独立驾驶试验区，暂不交付新的 EXE。已把可玩的第一版接入原网页版；原六章战役、成就与星星规则不变。

进入方式：主菜单 → 选择关卡 → 荒原先遣 / 载具试验。也可在现有游戏服务打开 `/vehicle.html`。该场景是独立原型，不是第七章。

## 已实现玩法

- 360 × 360 米有边界的试验场：环形道路、车库建筑、中央绕桩、东侧缓坡、六座按顺序通过的路线信标。
- 单座越野车：W 前进，S 刹停后倒车，A/D 转向，空格刹车。前进上限 29 m/s（约 104 km/h），倒车上限 9 m/s。
- E 上下车；上车需要距离足够近且无遮挡。车速至少 1.2 m/s 时拒绝下车。下车依次检查左右侧与后方落脚点，不能落进墙体；没有安全位置时留在车内。
- 步行与驾驶分开更新；下车后车辆保持停驻。步行也有环境及停放车辆碰撞。步行 Shift 加速。
- C 切换追尾和车头视角；步行鼠标观察；支持鼠标锁定或按住左键拖动观察。
- 车辆转向、车轮滚动、缓坡车身俯仰与轮位接地表现；追尾镜头进行遮挡缩短。
- 车速、挡位、累计里程、碰撞计数、路线计时、下一检查点距离及场地小地图。
- 六点路线只接受驾驶中的车辆，顺序错误或步行不会完成检查点。通过第一点开始计时，完成后可自由驾驶。
- 停车后按住 R 1.5 秒回收车辆；暂停界面提供二次确认回收。回收重置位置和本轮路线，不改任何原战役存档。
- Esc 暂停；窗口失焦/页面隐藏时清空按键并冻结车辆与计时，避免切回后持续油门或卡键。
- 进入试验区需要确认；战役结果待保存时拒绝跳转，暂停战斗离开时明确提示本轮挑战资格与阶段恢复的影响。

## 架构与大地图准备

- `vehicle-rules.js`：无渲染依赖的车辆控制、有限步长推进、碰撞、上下车、步行与路线规则。
- `vehicle-world.js`：试验场数据、可视场景、车辆模型。楼体、绕桩和路灯的静态碰撞数据统一提供给网格。
- `vehicle-app.js`：输入、步行/驾驶切换、暂停、镜头及 HUD 调度。
- `vehicle-entry.js`：进入试验区的菜单策略；不写存档。
- `vehicle.html` / `vehicle.css`：独立场景入口和界面。
- `menu-ui.js`：选关页增加入口，复用已有确认弹层；没有增加首页按钮或更改六章列表。

碰撞使用 24 米单元的静态空间网格，车辆用三圆组合保守近似车身占地，细分位移以避免高速穿过薄墙。远景岩石使用实例化绘制。这些是之后扩大场景的基础，并不意味着已经实现地图流式加载。

## 明确未实现

- 不是完整开放世界：没有区块加载、浮动原点、远距离导航或交通 AI。
- 没有车载武器、撞人伤害、车辆损毁、燃料、维修或多乘员。
- 当前为地面跟随/自行车转向模型，不是完整刚体模拟。缓坡接地表现不等于真实四轮悬挂；没有腾空、翻滚、轮胎摩擦圆或漂移系统。
- 试验区位置与本轮计时不持久化，退出、刷新或回收后重置。它不读写原有战役、星星、成就记录。
- 以桌面键鼠为目标。窄屏布局检查不代表已实现手机触控驾驶。
- 本轮没有重新打包 EXE；此前 EXE 不包含此次新增内容。

### 浏览器

`test-vehicle-browser.mjs` 使用隔离 Chromium、新浏览器上下文和真实页面键鼠事件；没有向游戏加入调试控制接口。

通过：上车、加速、拒绝行驶中下车、刹停、倒车、上下车往返、两种驾驶视角、暂停冻结、失焦暂停、二次确认回收、实际驾驶通过首个检查点、原存档键哨兵不变、960/390 像素宽度无横向溢出。页面脚本异常为空。

截图检查后将终点门移离出生车辆上方，避免其横梁遮住初始追尾视角；同时补上可见路灯碰撞和轮位缓坡接地表现。最终世界模块追加检查通过：实际创建 WebGL 场景、上车、车头视角与前进无页面异常。

浏览器运行在隔离沙箱的软件渲染环境；不能据此宣称 Windows 实机帧率达标、人工整圈驾驶体验已验收或原六章完成了新的浏览器全流程回归。

### 复跑浏览器测试

先运行现有游戏服务。浏览器测试需另备 Playwright 与 Chromium，不属于游戏运行依赖，本轮没有在 Windows 原项目安装 Playwright。

测试脚本默认使用 `http://127.0.0.1:5173/vehicle.html`；可用 `VEHICLE_TEST_URL` 覆盖。若 Playwright 安装在独立工具目录，用 `VEHICLE_PLAYWRIGHT_MODULE` 指向其 `index.mjs` 的绝对文件 URL。截图默认写入系统临时目录，可用 `VEHICLE_SCREENSHOT_DIR` 指定。

```bash
# 当 Playwright 可被 Node 正常解析时
node test-vehicle-browser.mjs
```
