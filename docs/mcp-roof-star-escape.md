# 第三章星星落地后无法离开：修复

## 原因

加难星星位于屋顶东南角（小地图右下角）。原隔离墙 x=8、z=22 及外围边界围成封闭区域。此前验证只覆盖从 7.25 米落到地面，没有覆盖落地后步行返回主路，遗漏了软锁问题。

## 修复

`roof-data.js` 将 x=8、z=22..38 的侧墙拆为两段，在 z=30..34 留出 4 米宽的永久地面出口，连接右下角区域和南部撤离区。z=22 主线隔离墙和门禁保持原状，不能借新出口跳过第一阶段。

`roof-world.js` 同步使用更新后的实体墙碰撞，增加青色地面方向标识和“返回主路 / EXIT”牌。沿右下角区域的青色指引向左走，可以回到南部撤离区；再绕过门锁终端，从已开启的主门返回战斗区。

星星位置、五段跳跃难度、收集存档及其他关卡均未改变。无需清空存档；重新加载新版地图后，恢复在右下角的有效检查点也能走出新出口。

## 验证

- 新增 `test-roof-escape.mjs` 并加入 npm test：真实高度掉落 → 地面出口 → 撤离区 → 主战斗区；额外三个落地点可返回；初始门禁仍阻挡北侧区域。
- 浏览器受控验证：完成第三关五次跳跃和收集，从最高点落地，保存并恢复受困区域检查点，再实际步行穿过新出口，回到 x=3,z=20 的主路；无页面异常。
- 最终远程 npm test 全量通过，exit 0；MCP 项目诊断 0 条。
- 此为受控输入及清除敌人的路径验证，不是人工完整战斗试玩。

## 后续方向

优先补充所有高处收集路线的“失败落点 → 可重试入口/主路”检查，避免只验证能落地而遗漏软锁；不额外提高已确认的星星难度。
