# 飞机 A/D 独立观察

## 需求与实现

- 用户确认：A/D 只旋转镜头，松手保持观察角度，不回中，也不带动飞机。
- 仅飞机改键；步行、越野车、游艇的 A/D 保持原行为。
- 飞机独立保存键盘观察偏角，速度 1.2 rad/s，范围左右约 77 度。
- 松开 A/D 不衰减偏角；鼠标航向收敛后也不清除键盘观察偏角。
- 鼠标仍更新飞机目标航向；镜头叠加键盘观察偏角，因此侧看时镜头朝向不再等于导航目标。
- 左右方向键保留手动滚转，Q/Z 保留方向舵；手动飞行输入优先于航向辅助。
- C 切换视角时重置观察；上下机、回收也重置。暂停保留角度并停止接收控制。
- 本文取代 [之前说明](mcp-yacht-speed-flight-look.md) 中 A/D 手动滚转描述。

## 验证

- 新增 [浏览器测试](../test-camera-browser.mjs)，沿用可选 Playwright 环境变量。
- 真实按键验证地面左/右观察、松手保持、暂停忽略输入、C 重置。
- 实际起飞后验证 A 不改变飞机目标航向或机头方向。
- 真实鼠标左右拖动验证飞机仍对准目标，且键盘观察偏角持续保留。
- 同套测试继续验证游艇超过 110 km/h、制动及禁止开放水域下船。
- 浏览器使用软件 WebGL；不代表 Windows 显卡性能测评。
