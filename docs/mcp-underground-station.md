# 第二张地图：地下运输站 / U-02

## 进入方式

主菜单和暂停菜单新增地图选择：01 反应堆设施 / 02 地下运输站。也可以直接访问 `http://localhost:5173/?map=station`。

第二张地图可直接进入，不要求先通关第一张。切换地图会重新加载页面，从而卸载上一张地图的场景与 WebGL 上下文；不是把两张地图同时保留在内存里。切换前未完成阶段的战斗进度不保存，回来时读取该阶段入口检查点。

## 已实现的五阶段

| 阶段 | 空间与任务 | 敌人 / 开门条件 |
| --- | --- | --- |
| 维护入口 | 低顶维修通道、配电柜、暖色应急照明；按 E 恢复供电 | 安全开场，无敌人；完成后打开站台隔离门，并切换照明条颜色 |
| 西侧站台 | 立柱、长视线、站台边线；清场后解锁停靠列车 | 5 名混合守卫；开启西侧车门 |
| 停靠列车 | 较低车顶、车窗、座椅、顶架、扶手与吊环；穿行并释放另一侧门锁 | 5 名混合守卫；开启东侧车门 |
| 调度室 | 从车厢东侧进入北部控制区；启动道岔切换 | 先清除 4 名守卫，随后 3 名增援；在 10 米内累计防守 18 秒，且清除剩余敌人后打开撤离闸门 |
| 末班列车 | 穿过西侧新开的通道，到白色列车内信标确认登车 | 4 名守卫；清场后按住 E 3 秒完成撤离 |

合计 21 名守卫、4 道有实体碰撞的任务门、8 处医疗/弹药补给。此图不重复放置反应堆或 Warden。站台强调掩体与远程威胁，车厢偏向近距离交火，调度室为定点范围防守。

这是新的可玩地图首版。列车当前为停靠状态，不是可驾驶载具，也没有列车驶出的结尾动画。主体仍是程序化几何与本地画布纹理，不是写实扫描素材。

## 门锁、导航与检查点

- 门有独立碰撞和渲染状态，完成前置任务后移除门的碰撞；重置较早阶段时会重新关闭后面的门。
- 门变化会使共享导航网格失效并重新计算，避免敌人继续沿旧的关闭路线寻路。
- 新地图使用固定且经过可达性验证的分区出生点，不会从第一张地图的散点规则中选出隔离区外的敌人。
- 地下运输站存储键为 `neon-eclipse.station.v1`；反应堆继续使用原来的 `neon-eclipse.campaign.v1`，原检查点不迁移、不覆盖。
- 检查点继续和阶段训练沿用现有机制。刷新后重建当前阶段的门锁、敌人、生命/弹药和已用补给。每张地图分别解锁自己的训练阶段。
- 调度室计时允许移动、射击与换弹；离开 10 米范围只暂停累计，按 Esc 冻结战场。计时结束仍有增援存活时不能直接完成。

## 模块

- `level.js`：读取地图参数、显示地图选择菜单。
- `station-data.js`：新地图阶段、入口、补给、墙体、掩体、门和出生点。
- `station-world.js`：独立站台/列车场景、实体门状态、照明、效果与静态网格批处理。
- `levels.css`：地图选择及菜单紧凑布局。
- `arena.js`：增加导航失效重建接口，保持原地图规则。
- 任务、任务 UI、无线电、雷达与存档根据当前地图使用相应配置。底部仍仅显示生命和弹药。

## 验证结果

`npm test` 增加 `test-station.mjs`，覆盖五个目标、21 名守卫、8 处补给的可达性，四道门隔离后续区域，开门后导航刷新，完整任务与撤离条件，以及存档键隔离。

本地 Chromium 受控测试通过：

- 从反应堆菜单真实切换到运输站；入口没有敌人。
- 完成供电、开门后通过通道；用实际移动碰撞函数依次走过站台、车厢、调度室和撤离列车，没有直接传送穿墙。
- 刷新后读取检查点，已完成的门打开、后续门保持关闭。
- 道岔触发 3 名增援；出圈暂停累计、Esc 冻结，计时结束仍需清敌。
- 最终登车才成功；完成运输站后返回反应堆，原检查点仍可读取。
- 页面 JavaScript 异常为 0。

第一张地图的任务/补给/撤离回归，以及精简 HUD、喷子装一发即可开火、近战挥砍的浏览器回归通过；纯逻辑测试保留枪械、敌方伤害和 Boss 规则覆盖。

测试使用受控清敌、位置路线和时间推进，不是完整人工战斗通关。敌人难度、弹药消耗、关卡时长和 Windows 真机帧率仍需试玩评估，不能用软件渲染截图里的帧率推断用户显卡性能。
