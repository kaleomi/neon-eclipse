# 高架守卫导航与运输安全门

## 本轮已实现

### 高架战斗

- 第三章普通守卫会使用已建成的检修楼梯上下高架，不再只在楼下追逐。
- 使用明确的地面入口、楼梯连接和高架区域规则，连接原有地面 BFS 导航。突击、远程和重装均支持；在高架上恢复各自接近、后退与侧移战术。
- 玩家回到地面后，守卫沿楼梯下来；移动步长受限，并阻止直接从平台边缘跨出或突然跨越较大高度。
- 修正真正发射子弹时覆盖枪口高度的问题：发射起点现在包含守卫脚部高度，与瞄准时使用的高度一致。
- 守卫分离逻辑仅作用于脚部高度差小于 0.6 米的对象，避免上下两层隔着地板互相挤开。

这不是通用三维导航网格。当前覆盖第三章已建成的楼梯与主高架；守卫不会搭乘运输车台前往远端泊位，也不会自动跳跃、攀爬或穿越任意新楼层。Boss 没有新增跨层移动。

### 运输安全

- 主高架与远端泊位的登车口增加橙色安全门，具有玩家碰撞。
- 车台停靠时门打开，离开时门关闭。玩家处在门口的身体范围内时，不强行关闭。
- 增加当前停靠状态和距离出发的秒数；修正旧提示字符串把换行显示成文字的问题。
- 运输网格随真实车台位置更新；保留原有承载、暂停和检查点时钟恢复规则。
- 本轮没有增加全周护栏、呼叫按钮、车辆驾驶或地下站移动列车。安全门只管理玩家登车口，不是整套敌人登车与门禁系统。

## 如何体验

Ctrl+F5 刷新第三章。进入阵列区后，从东侧约 `(20, 5)` 的楼梯上到高架，观察附近守卫沿楼梯追击及高处射击。返回地面后观察守卫回到地面。建议先用已解锁的第二阶段训练测试，避免覆盖正在推进的战役。

在高架东侧登车口等待运输车：橙门关闭时等待，车台停靠后开门，并显示出发倒计时。远端泊位同样处理。

## 主要文件

- `roof-enemy-navigation.js`：第三章静态楼梯连接、高度移动、同层判断与枪口高度。
- `enemy-ai.js`、`app.js`：连接导航和战术控制。
- `boarding-rules.js`、`transport-world.js`：停靠判断、倒计时、安全门及提示。
- `test-height-navigation.mjs`、`test-height-director.mjs`：自动回归；加入 `package.json` 的测试脚本。
