# P1 第三批：TEMPEST 机动冲锋枪完整链路

日期：2026-09-18

依据：`docs/mcp-full-development-plan.md` 第 5.2 节、`docs/mcp-p1-weapon-registry.md` 的下一批方向及 `docs/mcp-phase0-engineering-baseline.md` 的协作边界。

**本批交付首把新增武器，不代表整个 P1 完成。只更新源码，不制作 EXE。**

## 1. 玩家入口与行为

- 新增 TEMPEST 机动冲锋枪，六章均可按 **5** 选择。原 1–4 键顺序保留：VANGUARD、BREACHER、GHOST、ARC BLADE。
- 当前暂为五把随身武器，不提前引入方案最终的携带限制或装备替换菜单。
- TEMPEST 配置：36 发弹匣、180 发备用、16 基础伤害、0.065 秒开火间隔、1.5 秒整匣换弹、42m 射程、14m 开始衰减、最远伤害系数 0.35、头部倍率 1.55。
- 低伤高射速；移动散布增量为 4%，其他武器仍使用原有 55% 增量。基础散布 0.016、后坐力 0.008，因此不将机动优势宣称为静止精准度全面优于步枪。
- TEMPEST 在不瞄准、不射击时可以持 Shift 移动并持续换弹。开火和 ADS 仍停止冲刺。旧四把武器的换弹/冲刺规则保持原样。
- 换弹过程只有完整装填结束才转移弹药；切枪取消未完成换弹，暂停冻结并可继续。空枪不凭空产生子弹。
- 新配置为 `weapons/tempest.js`；`movementPenalty` 与 `sprintReload` 是经过静态校验的可选配置，默认值保留旧行为。

## 2. 模型、动作、声音与 HUD

- 独立紧凑机匣、短枪管、枪托、直弹匣、双照门和机身发光条；不是直接把步枪改名。
- 独立模型名称与运行时 ID；第五把使用既有弹匣/支撑手/枪机动作框架，具备换弹抽匣、枪机回动及开火后坐表现。冲刺换弹降低持枪下沉幅度，保留动作可见性。
- 枪口火光/曳光起点匹配短枪管位置。
- 新增 `fire.tempest` 高频短促射击音与 `reload.tempest` 换弹起手音，接入现有音频总线、音量、暂停和静音策略，不新增音频运行时依赖。
- 第五张武器卡及独立枪械 SVG，保留原卡顺序；弹药栏显示 TEMPEST，装填提示显示“可冲刺”，操作说明更新为 1–5。
- 五张卡片适当压缩高度，原精简/缩放规则仍生效。已检查远端 1280×800 实际游戏截图；截图中的软件渲染 FPS 不是实机性能指标。

## 3. 存档与补给兼容

### 兼容注册表与运行时分开

- `WEAPONS`、`LEGACY_WEAPON_IDS` 和原数字索引接口仍保持四把历史武器；现有数值和对象形状由上一批精确回归锁定。
- `WEAPON_DEFINITIONS` 可查询 TEMPEST 的稳定 ID；新增 `weapons/runtime.js` 提供五槽运行时配置及兼容辅助函数。
- `getWeaponId(4)` 仍是 null，避免把历史索引接口悄悄改成新的存档编号。运行时第五槽由 `RUNTIME_WEAPON_IDS[4] === 'tempest'` 明确声明。

### 检查点是可选扩展，不是全局迁移

- 原 `rounds` / `reserves` 仍各三项，原 `selected` 范围仍是 0–3，不改变存档键或版本。
- 新增可选 `tempest: { rounds, reserve, equipped }`。TEMPEST 选中时旧 `selected` 写 0，新程序通过 equipped 恢复第五把；旧程序若读取该存档会安全回到原步枪，而非把第五把的弹药塞进步枪。
- **旧存档无扩展时**：历史弹药与选中武器原样恢复，新增武器获得初始弹药。
- **新存档有扩展时**：精确恢复冲锋枪弹药与选中状态，零弹药也保持零，不通过重试补满。
- 非法弹药上限/负数/字段类型以及 equipped 与旧 selected 冲突被检查点验证拒绝。
- 单章和战役使用同一检查点校验；SaveHub 仍按原槽位原文备份/导入，无须改动 SaveHub、地图注册表或遥测模块。新增测试实际覆盖 SaveHub 导入及恢复备份时该扩展的保留。
- 旧程序若重新保存而丢弃未知扩展，再回到新程序时视为旧存档；不宣称旧程序能够理解或持久化 TEMPEST。
- 弹药补给额外提供 72 发冲锋枪备用，上限 180；只缺冲锋枪弹药时补给仍可领取，全武器满弹时不浪费补给；医疗箱不补弹。原三种枪械补给数量不变，没有共享弹药池。

## 4. 统计、成就与回归中修复的问题

- TEMPEST 实发计入阶段耗弹与纯刀资格；对墙或未命中的开枪也取消纯刀资格。
- 原“全武装制霸”仍要求原四把各击破，不用冲锋枪击破冒充步枪；未改成就条件或旧记录。
- 本地遥测按武器数组追加第五项，前三枪/第四刀索引不变；沿用 P0 允许可变长度数组的原实现，未修改遥测模块。
- 监察者战斗记录追加可选冲锋枪开火数及剩余弹药，不把新枪计作步枪或漏记。
- 首轮旧武器浏览器检查暴露切枪瞬间准星可开火样式仍为上一帧的问题：实际切枪锁定 0.22 秒尚未结束，快速点击可能在锁定期间耗尽原输入缓冲。新增即时准星隐藏，使 HUD 与实际锁定同步；没有缩短锁定或更改旧开火间隔。
- 首轮 smoke 暴露开始/暂停后 `data-play-state` 等待下一动画帧的问题：菜单已经关闭，标签仍为 ready。现在进入游戏、暂停和结束时同步更新标签，原状态机与输入规则不变。
- 上述问题修复后重跑原测试通过，没有通过删除检查或放宽预期掩盖失败。
