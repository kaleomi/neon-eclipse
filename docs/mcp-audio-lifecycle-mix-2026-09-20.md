# 音频生命周期与分组音量：本批交付

日期：2026-09-20；项目：`game/`。

## 修复内容

在 `audio/audio-bus.js` 修复异步暂停／恢复竞争：原实现只检查调用时的 AudioContext 状态，延迟完成的 resume 可能覆盖刚加入的 hidden 原因；反过来，延迟 suspend 也可能让已恢复的游戏继续静音。

新增确定性延迟测试先在旧实现复现失败，证据 `.tools/audio-race-before.log`。修复将状态切换串行化，每次异步操作完成后重新核对当前暂停原因；`ready` 同时检查暂停意图，阻止暂停请求后的新音效进入。多重暂停原因、重复解锁及失败后重试保持可用。

未修改音量默认值、混音增益、音效／配乐文件、淡入淡出参数、许可署名、战斗或存档规则。保留其他会话改动，未提交、推送或打包。
