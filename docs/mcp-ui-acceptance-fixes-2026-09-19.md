# NEON ECLIPSE｜首轮人工验收反馈修正

日期：2026-09-19。基线提交：`939bd1c`，本批为其上的工作区改动，未提交、未推送、未制作 EXE。

## 用户要求与实际变更

### 1. 开场跳过与遮挡

根因是 `presentation-fx.css` 中 `.chapter-intro`、目标卡等元素显式使用 `display:grid`，覆盖浏览器对 `hidden` 属性的默认隐藏规则；原浏览器检查只确认属性，没有确认实际可见性。

- 为开场层及其隐藏子元素加入明确的隐藏规则，不再出现逻辑已结束而视觉仍覆盖的状态。
- 空格/回车通过捕获阶段处理，不受仍聚焦的菜单按钮或跳跃重绑影响；取消强制最短观看等待。
- 增加可见的“关闭 ×”，保留鼠标跳过；锁定鼠标时原生左键点击也能跳过。Esc 关闭开场并保持原有暂停菜单行为。
- 自动结束使用真实帧间隔，而不是受 `.05` 秒上限影响的游戏模拟间隔，避免低帧率把十秒开场拖得很长。
- 跳过/结束恢复相机、武器与输入状态，不把空格继续当成一次持续跳跃。

### 2. 滚轮与实际携带槽

`weapon-selection.js` 按实际携带的主武器、副武器、近战循环；向前/向后均可，未携带枪不会出现在循环中。支持滚轮和高分辨率触控板，加入一次手势限速；暂停、菜单/装备面板、文本/选择控件和 Ctrl/Cmd 缩放不抢输入。

特殊主武器也能通过滚轮选中，使用独立的临时逻辑选择状态，不把 8–10 写入旧的 0–7 弹匣数组索引。灰烬榴弹炮/光矛穿甲炮可用左键按原规则射击，光矛仍要求完全开镜；R 为所持重炮装填，H 兼容入口保留。近战锤继续使用近战槽与原有挥击规则。没有更改伤害、射速、解锁条件或旧存档字段结构。

### 3. 中文武器名称与三槽 HUD

`weapon-display.js` 统一玩家可见名称；内部字符串 ID、数字槽位、存档键和统计字段不翻译、不迁移。覆盖常规枪械、刀/锤、重炮，装备面板、改装工坊、掉落提示、档案和 P4 武器统计的相关显示。

对应名称包括先锋突击步枪、破门霰弹枪、幽灵消音手枪、电弧战刃、风暴冲锋枪、光环精准步枪、磁轨穿透枪、雷霆电弧霰弹枪、重型脉冲炮、灰烬榴弹炮、光矛穿甲炮、破阵重锤。投掷物状态补充“电磁脉冲手雷”中文主名。

右侧只创建三张实际装备卡，主武器在前、副武器其次、近战最后；切换主武器或刀锤后原位替换，不展示未装备库存。库存和解锁仍通过 U 装备面板管理，没有删除。

### 4. 卡片下方的百分比弹药条

- 有限弹药显示 `(当前弹匣 + 本枪可使用的备用弹药) / (满弹匣 + 对应储备容量)`。
- 共享类型弹药按本枪单发成本换算，并标明共享类型；这些储备不能跨枪重复相加。
- 装填只是从备用转移到弹匣，因此不会使总量条凭空上涨；两者都空时显示 0%。轻量库存容量也被纳入分母。
- 近战显示“不消耗弹药 / ∞”，不伪造 100% 有限弹药；未知未来版本数据保留只读边界。
- 截图复核发现原全息皮肤固定 55/61 像素卡高造成新增弹药行溢出，已改为内容自适应、恢复可读字号，并将投掷物状态放入同一纵向布局，避免与右下角状态交叠。

### 5. 掉落外观与频率

- 普通可掉枪人形敌人从必掉改为 **25%**；适用角色仍为突击兵、远程兵、重装兵、港口精英、工程兵、指挥官。Boss、机械等原本不掉枪的对象没有新增掉落。
- 每个尸体最多判定一次，失败回调不能重复抽奖；场上最多 **4 把**，满池复用最旧槽位。
- 六类敌人掉枪与三类固定重武器领取点使用九种几何轮廓：枪托/弹匣/护木、粗管泵动结构、短枪身长弹匣、瞄具、长双轨线圈、双发射口/电池鼓、榴弹鼓、重型穿甲长管及宽锤头。
- 色彩是辅助提示，不是唯一辨识方式；模型不参与射线阻挡，模板共享材质/几何体，拾取或重置不重复分配整套资源。
- 固定领取点概率和关卡奖励不变；F 拾取只替换主武器，不补弹、不重置生命、挑战、解锁或已保存库存。

### 保留的失败与限制

- 补丁初次因 Bridge 未在 schema 列明的操作/路径上限被预检拒绝，明确没有读写文件。随后按依赖分为不超过 20 路径的版本保护补丁；没有宣称整批跨文件系统原子提交。
- 首轮新浏览器脚本确认空格/回车通过，但 Playwright `locator.click` 在光标锁定下被画布拦截并超时。第二轮改为真实鼠标坐标输入（不是强制 DOM click），保留“开场实际 display:none”的断言并通过。
- 掉落回归显式固定 RNG 以覆盖“确实掉落”的拾取链路；生产 25% 阈值和失败尸体不重抽由独立规则测试覆盖。旧零弹药测试同步清空权威类型弹药池，避免只清空旧镜像数组而宣称储备为零。
- 浏览器运行中 MCP 快隧道多次短暂返回 502/530，均仅重试只读查询并取回原命令状态；未重复启动仍在运行的测试。
- 第一轮版式截图在软件 WebGL 环境超时（字体已载入后仍未取到画面）。复测使用性能档、测试响应中的单帧读取，保留全部位置断言后通过；冻结仅在测试中注入，正式游戏不会为了截图停止渲染。
- 未重跑所有历史浏览器专项；其中旧“八张库存卡”的显示断言改为“三张实际装备卡”和稳定武器 ID 定位，不再以 DOM 序号代表武器槽。
- 全部浏览器测试使用独立端口/上下文，不操作用户真实存档。场景/弹药夹具和软件 WebGL 只证明接线与回归，不等于真人通关、长期稳定性、平衡或真实 GPU 性能验收。
