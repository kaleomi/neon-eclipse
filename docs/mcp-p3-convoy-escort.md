# P3 第二批交付：先遣队第 1 关「荒原车队护送」

日期：2026-09-18
依据：`docs/mcp-full-development-plan.md` 第 7.5 节（先遣队战役线）与 7.1/7.2 的衔接要求。P0 / P1 / P2 由其他 AI 负责，本批只接手 P3 载具域源码，不制作 EXE。前一批见 [P3 车载武器与耐久交付](mcp-p3-vehicle-weapons.md)。

## 交付边界

**这是 P3 的第二批，不是整个 Phase 3 完成。** 完成的是 7.5 先遣队战役的第 1 关，并首次把第一批的车顶机枪、载具耐久接进一个有敌方目标、有失败条件的任务。7.3 直升机等新载具、7.4 大地图流式、7.5 第 2 关及之后（含检查点保存、战役成绩）均未开始。

本批完成：

- **运输卡车自动行驶**：从车库出发沿场地环线（离开车库 → 北侧弯道 → 东北弯道 → 东南弯道 → 南侧哨站）以 11 m/s 自动行驶。护送车落后 70 米以上卡车停车等待，回到 45 米内恢复。卡车有 100 点耐久、能阻挡越野车通行（不能穿过它）。
- **猎犬机伏击**：环线西、北、东三处固定伏击点，卡车进入 40 米触发半径时按难度放出 2～4 只猎犬机；同一波按 0.7～1.2 秒错峰释放。猎犬机状态机：`hold → approach → telegraph → lunge → recover`。接近到 22 米内锁定较近的卡车 / 越野车，**锁定点在地面画出红线并冻结**（按预警时长 × 目标速度提前量，最多 18 米），预警结束后沿红线突进 1.15 秒，命中只结算一次，随后绕目标 1.8 秒再重新接近。猎犬机被地形 / 建筑阻挡时会尝试 ±40° / ±80° 绕行；突进期间不穿墙。
- **躲避与打断**：预警期间击毁猎犬机即取消突进；卡车或越野车在红线消失前离开锁定点 2.4 米以外则突进落空。
- **车顶机枪接入**：护送中越野车武器保持启用，猎犬机作为射线目标进入同一套 `hitscan / damageTarget` 逻辑；打中猎犬机不计入靶场统计，打中靶场靶标仍计入靶场统计。
- **炮手位自动跟随**：护送中按 F 进入炮手位后，车辆自动保持在卡车后方约 12 米（不是第一批的"直行 3 秒"），耐久降档仍按第一批规则限制油门 / 转向；回驾驶位可手动挡车。任务从炮手位开始。
- **失败条件**：卡车耐久归零，或越野车耐久（第一批 `vehicle-durability`）归零。猎犬机撞越野车走 `applyDamage`，同时附加向前推力，撞击后越野车会冒烟 / 失效。
- **胜利条件**：卡车抵达南侧哨站 + 三处伏击都已触发 + 场上无存活猎犬机。
- **难度**：简单 / 普通 / 困难（暂停菜单下拉），只写 `neon-eclipse.escort-difficulty.v1` 一个键。
- **表现层**：卡车模型（受击闪白、等待时顶灯变橙）、猎犬机池（12 个，预警时体色转橙红并抖动，突进时腿部摆动加快，残骸半透明）、地面红线 + 锁定环、沿途路标柱（当前目标呼吸）、终点光环、小地图卡车 / 猎犬机 / 终点标记；右上新增"车队护送"面板（卡车耐久条、猎犬机存活/击毁、伏击波、状态行，预警时面板整体转红）；任务栏、路线条与引导标记均改为指向卡车当前路段。

## 与既有任务的关系

| 项目 | 规则 |
| --- | --- |
| 海空接力 / 南湾突围 / 归航 / 侦察 | 与护送互斥：开始护送先 `recover('garage')` 重置一切；开始其他任务同样重置护送 |
| 武器 | 护送中**保持启用**（`armed()` 未把护送列入停用任务）；飞机机炮 / 火箭在护送中同样可用但没有意义（不能下车） |
| 下车 / R 回收 | 护送中 E 拒绝下车、R 不回收；Esc 暂停后可重试或"结束护送，返回自由试驾" |
| 耐久与维修 | 越野车耐久用第一批同一份 `wear.rover`；停回车库仍会维修，但卡车不会等在车库 |
| 存档 | **不写任何存储**（难度键除外）。没有检查点、成绩、战役进度；失败或成功都只能重试 |
| 回收 / 试验调度 | `recover()` 把护送置回 idle，卡车与猎犬机全部清除 |

数值来源：本批未有真人遥测；数值由本地 60 Hz 自动跟随 + 不同命中率的模拟炮手推出（首版出生点 45～60 m、HP≈30 时三档都零伤害，因此收紧到现值：普通档满命中卡车 ≥88%；困难档弱命中卡车约 30%～58%、越野车 40%～100%，都能通关但有压力）。**需要真人试玩数据再调，不在没有数据时进一步削弱。**

## 已知限制

- 猎犬机只会突进，没有远程攻击、没有互相协同；同一波最多 6 只在场。
- 卡车不会躲避、不会反击，路线固定；越野车挡在卡车正前方时卡车会顶着走（卡车不检测越野车碰撞，只有越野车被卡车阻挡）。
- 自动跟随只追踪卡车后方 12 米的位置，不避障；在弯道内侧可能蹭到路标柱或建筑并扣耐久。
- 没有检查点或中途保存；没有成绩、成就、战役进度写入。
- 只有一关；7.5 中的第 2 关及以后、以及与 7.1 联合检查点的战役串联未做。
