# 场景任务引导与侦察高度带

## 最新要求

**用户明确要求：后续不再制作 EXE，只更新游戏源码。** 本轮未修改桌面目录、未打包、未覆盖已有 EXE。当前体验入口是更新后的网页载具试验区；旧 EXE 不包含本轮改动。

## 已完成

- 当前目标直接显示在画面中，包含名称、距离，以及目标离开视野时的方向提示。
- 接入飞行任务、海战路线、自由驾驶路线和初始越野车上车目标；暂停时隐藏场景引导。
- 低空侦察当前目标增加半透明金色圆柱、上下边界光环及竖向轮廓线，明确表现可飞入的三维区域。
- 北侧中继站：30–60 米；近海信标：60–90 米；机场南侧终端：30–60 米。半径均为 90 米。
- 圆柱只强调当前扫描目标，完成后切换到下一处；扫描结束后隐藏圆柱，目标提示转向返航进近及跑道。
- 醒目的高度提示显示要求高度、当前高度，以及过低、过高或高度合格。扫描条件提示使用任务实际判定结果，不用另一套近似遮挡规则。
- 圆柱内仍需满足航向、速度、滚转、升降率、无遮挡及按住 F 等条件；进入圆柱不代表自动扫描完成。
- 近距离限制世界文字牌的视觉尺寸，并调整窄屏布局，避免新增高度提示覆盖原飞行仪表。

高度显示沿用现有规则 `plane.y - 1.3`，所以圆柱世界坐标上下边界分别为要求高度加 1.3 米。没有改变扫描数值、任务难度、计时或成绩版本；也没有为圆柱增加碰撞。
