## 一、低空侦察怎么玩

入口：主菜单 → 海陆空试验区 → 开始/暂停面板 → **低空侦察 · 回声航线**。向下滚动找到任务，点击开始并再次确认。

流程：

**机场起飞 → 北侧中继站 → 近海信标 → 机场南侧终端 → 北向返航进场 → 跑道着陆停稳 → 按住 F 上传 → 结算。**

全程限时五分钟，准备、滑跑和地面上传都计时。

| 地标 | 高度带 | 目标航向 |
| --- | --- | --- |
| 北侧中继站 | 30–60 米 | 约 0°，北向 |
| 近海信标 | 60–90 米 | 约 100° |
| 机场南侧终端 | 30–60 米 | 约 241° |

### 扫描规则

- 按顺序进入地标 **90 米水平范围**，在空中保持指定高度和航向。
- 机翼滚转不超过约 29°，升降率绝对值不超过 6 米/秒，速度在 22–50 米/秒之间，目标不能被实体遮挡。
- 同时按住 **F，连续保持 1.5 秒**，才记为该地标扫描成功。
- 松开 F、飞出范围、偏离高度/航向或失去稳定条件，会清零当前扫描进度；已完成的地标记录不会因此丢失。
- 扫描状态栏显示条件提示、当前进度、记录数量；仪表显示当前航向，可与左上目标航向对照。
- 加入地标全息标记、扫描范围和方向提示；侦察任务隐藏旧五门练习的引导环，避免混淆。切换回归航试炼或自由试飞会恢复旧引导。

这是按规定航线方向进行的稳定扫描任务，不是自由拍照或摄像机瞄准系统。地标采用非实体全息标记，不新增阻挡旧航线的障碍物。

### 返航与上传

三处扫描完不立即成功。仍须通过原返航进场门、北向对正着陆、收油刹停并连续停稳两秒。

停稳后进入独立“返航上传”阶段：**保持停稳，按住 F 两秒**。松键或不再满足停稳条件会清零当前上传进度。只有完整、顺序正确的三份扫描记录才能上传并成功结算。

“上传”是游戏任务内的模拟通信，**不连接远端服务，也不保存历史成绩**。

### 保持和隔离

- 沿用归航任务的失败、暂停、失焦、重试、退出与安全着陆机制。
- 重试会重开同一种任务，清空本轮扫描与上传进度，不会误切回归航试炼。
- 归航、侦察与海战通过确认后互相切换，清理旧任务状态与海战弹道。
- F 在飞机侦察中用于扫描/上传，在海战中仍用于舰炮；两者不会同时运行。
- 不修改飞机物理、鼠标+A/D 操控、W/S 反向偏好、游艇手感、六章存档格式或主线全息 HUD。
- 返回主菜单、调度、重试或刷新会按试验区原规则重置任务；不写入战役、星星和成就存档。
