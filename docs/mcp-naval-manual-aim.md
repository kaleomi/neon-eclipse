# 第二关操控调整：自由环视、手动舰炮与矩形尾流移除

日期：2026-09-18。用户要求第二关不再固定视角、可以朝后看，鼠标控制炮塔瞄准、左键攻击，并检查移除船底的大长方块。关联 `docs/mcp-stability-plan.md`。

## 本批实现

| 操作 | 当前行为 |
| --- | --- |
| 鼠标左右 | 艇上水平方向 360° 环视/瞄准，可向船尾射击；世界瞄准朝向独立于船舵 |
| 鼠标上下 | 调整海面准星远近与俯视程度；沿用二维海战射线，不引入对空仰角弹道 |
| 左键 | 向海面准星方向发射舰炮；可以打空海面，不要求有可锁定敌艇 |
| F | 保留为同一手动射击的兼容键，不再自动瞄准敌艇 |
| Q | 切换查看敌艇耐久/状态，不转动炮口，不重置装填 |
| W/S、A/D、空格 | 仍为油门/倒车、船舵、刹车；鼠标不控制船舵 |
| C | 保留追尾/近舱视角切换，保留世界瞄准方向 |
| 指针锁定不可用 | 船上可以右键拖动瞄准、左键射击；释放左键不会中断仍按住的右键拖动 |

暂停保持瞄准方向但清除按住的射击；重试、上下艇及检查点恢复重新建立船舶朝向基准。界面、海战说明、准星和观察目标文字同步更新。

## 矩形物体定位

`createYachtModel` 原本在船尾生成无纹理的 `PlaneGeometry(4,15)`，随速度拉长并提高不透明度。这确实是一个可见长方形尾流面片，很可能对应用户报告的方块。

已移除这块尾流网格，玩家艇和敌艇都不再绘制它。保留空 Group 作为旧 `wake.visible` 调用的兼容句柄，不存在可被重新打开的矩形几何。没有删除船壳、甲板、码头、海面或碰撞结构。

**尚无用户截图，不能百分之百认定报告指的就是这块面片。** 若刷新后仍能看到方块，需要截图进一步定位，不盲删其他模型。

## 规则与状态边界

- `naval-aim.js` 保存独立世界朝向，提供海面瞄准点和相机位置；相机对准同一个瞄准点，回归检查其投影落在屏幕中心。近/远视角均覆盖。
- 实际载具入口每次向 `stepNavalMission` 传入明确的 `aimPoint`。Q 的选择仍供状态面板使用，但不能改变手动发射方向。
- 手动炮弹放入独立的 `naval.playerCombat`，避免其因被观察敌艇沉没而被错误清除；敌艇自己的炮弹/预警仍分开管理。
- 手动炮弹仍有飞行时间、扫掠命中与陆地遮挡，可以击中非观察目标；沿用伤害、弹速、射程判定、1.6 秒共享装填和敌方参数。非法/非有限瞄准点不会回退成自动锁定。
- 结算/中止清理独立炮弹；新任务和安全节点恢复重新创建炮台状态，不继承旧弹体或装填。没有修改存档键、schema、检查点模板、恢复资格或成绩格式。
- 未传 `aimPoint` 的既有规则调用仍保留旧辅助瞄准接口，便于兼容已有规则测试；实际页面左键和 F 均走手动瞄准路径。

## 用户复测

1. 在节点明确显示保存成功或确认本轮可以重试后强制刷新载具页。刷新不保留未保存的实时位置。
2. 进入第二关南湾突围；左右移动鼠标到船尾方向，应可完整环视。
3. 保持船尾瞄准并转动船舵，确认画面不被船头方向拉回；左键应向准星方向射击，不被 Q 观察目标牵走。
4. 暂停/继续、从安全节点恢复后确认没有残余开火，鼠标和左键仍可使用。
5. 检查长方形面片是否消失；若仍有其他方块，请提供截图。

真实指针锁定、各分辨率 HUD 遮挡、近岸相机碰撞、手动瞄准手感与完整任务平衡仍待人工确认。海面准星只改变水平射击方向，不是可自由抬炮攻击空中目标的新武器。
