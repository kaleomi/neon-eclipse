# K-19 霓虹工业美术迭代

## 美术方向

石墨蓝装甲、离子青光源、琥珀橙警戒色。保留现有工业反应堆题材，不引入外部图片或字体。所有本轮贴图均在 art.js 内通过 Canvas 生成，使用 Three.js 几何体建模。

## 本次改动

- art.js：墙板、铆钉、格栅地板、警戒条、工业标牌、顶部管线、反应堆约束笼与动态能量环。
- 四套独立武器几何组：带瞄具步枪、双管霰弹枪、短枪与三棱能量刃；调整枪体比例及金属可读性。
- 守卫增加肩甲、膝部护板、关节、背包；Boss 增加双肩结构和冠状能量环。
- 命中火花、击破粒子、空气微粒、光晕；粒子批次上限 24 并在结束时释放资源。
- art.css：青橙战术 HUD、方位指示、左对齐任务界面。菜单隐藏战斗 HUD，避免信息重叠。
- 静态方块按材质进行实例化绘制，测试场景生成 9 个批次；保留原碰撞网格用于射线判断。
- Q 或菜单画质按钮切换精细/性能模式：性能模式降低渲染分辨率并隐藏空气微粒。
- 移除 style.css 的 Google Fonts 请求，使用系统字体；npm test 覆盖 app.js、art.js、server.cjs 语法。

## 验证

独立 Linux Chromium 副本完成：画面初始化、射击扣弹、切枪、换弹、暂停；测试模块注入（不进入正式代码）验证四套武器、实例化网格、装甲目标命中、反应堆掩体遮挡、五波状态推进、最终 Boss 生成、胜利与重置。页面 JS 异常为 0。检查了 1440×900 菜单和实战截图并据此修正照明、枪械大小。

状态推进测试通过人工清空敌人完成，不等同于完整人工通关。Linux 软件渲染环境帧率较低，不作为 Windows 实机帧率指标；需要用户在本机启用硬件加速并试玩确认性能，必要时按 Q。尚未进行长时间稳定性、完整难度平衡或移动端触控验收。

## 运行

项目目录 npm run dev，浏览器打开 http://localhost:5173。已有服务运行时刷新页面即可；缓存旧资源时使用 Ctrl+F5。原有 WASD、Shift、鼠标、R、1–4、Esc 操作不变，新增 Q 画质切换。
