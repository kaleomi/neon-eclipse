日期：2026-09-20；项目：`game/`。

- 新增只读 `combat-cue-model.js`，统一护盾、暴露、预警／列车通行和完成状态的文字与符号。

2. 新增浏览器测试通过 45 组布局：1440×960、1024×640、390×844；五种色觉模式；护盾、列车通行、暴露三种状态；HUD 115%。另测 WARDEN 三态、待发车和完成状态、实际改键、减少动效、暂停隐藏、规则及存储不被提示更新改写。
3. 原有 HUD 回归通过：9 组警报布局、实际键名／换弹／耗尽／近战状态、12 组暂停与结算布局。
4. 原生运输站专项五组通过：地图启动及跨图面板、调度门槛与暂停、实际 E 交互与六秒暴露窗口、八种武器真实攻击路径、死亡／重试／检查点／撤离；无页面错误或存档结构变化。
5. 最终命令退出码 0，标记 `COMBAT_CUES_FINAL_EXIT=0`；日志 `.tools/combat-cues-final.log`。IDE 错误／警告诊断返回 0。

初次布局测试捕获 390 像素宽、115% HUD 下敌人信息卡与武器栏重叠；调整卡片宽度和位置后完整重跑通过，没有删除重叠断言。已查看 390 和 1024 宽截图；三种尺寸截图位于 `.tools/qa-combat-cues/moving-*.png`。

## 范围与边界

生产修改限于 `combat-cue-model.js`、`enemy-ui.js`、`switchyard-ui.js`、`ui-clean.css`。没有改地图碰撞、路线、预警时长、命中／伤害、Boss 规则、存档或解锁。

45 组新测试是使用实际 DOM 控制器、Three 射线检测与二维明暗背景的受控夹具，不运行完整 WebGL 战斗。色觉模式检查了设置与画布滤镜接线，但不能代替真实雾效、暗处、各种敌人三维预警及实机色觉体验验收。截图中的任务、帧率等是夹具内容，不能当作实战或性能证据。原生关卡回归单独运行，也不等同九章自然通关。

本批只完成战斗提示的 HUD 试点，不宣称全部世界空间预警已经验收。下一步优先补普通敌人／世界预警在真实场景中的检查，再进入音频混音与生命周期。保留其他会话改动；未提交、推送或打包。
