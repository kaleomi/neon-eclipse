## 越野车引擎音量

`audio/vehicle-audio.js` 中只将 roverEngine 的引擎增益乘以 **0.65（约 -3.7 dB）**。这是线性增益比例，不是“主观响度下降 35%”的承诺。

保留频率、负载响应、滤波曲线与风声；不改总音量/玩家偏好，不调低飞机、游艇、枪声、命中、警告或任务提示。新音量是否合适仍需用户实际试听。

## 地面闪烁定位与修复

代码与向下射线检查确认：旧试车场的 440×440 地形和海空基地整块底板覆盖了同一区域。平坦区域地形表面约 **y=-0.025**，底板顶面约 **y=-0.055**，只有 3 厘米差距。它们在高空/远距离观察时可能竞争深度，与用户描述的交替闪烁一致；底板还是一个投射阴影的薄盒体。

本次采用结构性修复，不靠改变颜色或关闭深度测试掩盖：

- `buildSeaAirField(scene,{provingGroundPresent:true})` 将基地基础地面分成西、北、南三块，绕开原试车场的 `[-220,220] × [-220,220]` 区域；覆盖总范围仍为 x=-600…220、z=-600…600。
- 基地基础地面使用朝上的单面 PlaneGeometry，接收阴影但不投射自身地面阴影，不再保留薄盒体上下表面。
- 外围地面与原地形平坦边界对齐为 y=-0.025；保留原中央坡地几何和 terrainHeight 规则。
- 默认未传选项时仍铺满基地陆地区域，独立调用不会因缺少原试车场而出现中心空洞。
- `vehicle-app.js` 的组合场景明确传入该选项。没有修改碰撞、道路位置、跑道、码头、海面、存档或玩法数值。

截图与用户的动态报告用于定位，静态图本身不是 GPU 帧间闪烁的复现。自动测试确认重叠结构已消除；是否消除了实机上全部闪烁，仍需沿原观察路线复测，不将其他道路标线/阴影情况预先判定为通过。
