## 一、归航试炼已经实现

任务流程：

**机场开始 → 滑跑起飞 → 顺序通过五个三维导航门 → 青色返航门北向对正 → 指定跑道着陆 → 收油刹停 → 成功结算。**

- 从开始任务计时，限时五分钟，准备和滑跑也计入时限。
- 航点按顺序并按三维位置判断；在地面经过不计入。
- 五门完成后仍在任务中，不能在空中提前获得成功。
- 返航门有北向航向与运动方向要求，增加场景引导环、文字、小地图返航标记和跑道亮线。
- 必须在标记跑道上北向对正着陆，随后将油门降到 5% 以下、速度不超过 1 米/秒，并连续保持两秒。
- 提前着陆、错误着陆、受损、越界、超时或任务位置异常跳变会失败。
- 成功/失败后冻结任务；可直接重试，或回到机场自由试飞。
- 暂停和失焦冻结计时与载具；中途离机、按住 R 快速回收不能绕过任务规则。
- 飞行任务与海战互斥，明确确认后切换；重置时清理旧任务状态和海战弹道。

### 保持不变的内容

没有改动飞机物理、鼠标航向与 A/D 叠加、W/S 反向偏好、游艇速度与刹车、主线战斗参数、六章存档和全息 HUD。

任务不保存历史成绩，不颁发主线成就，也没有自动驾驶或自动降落。测试驾驶控制器仅存在于 `test-flight-pilot.mjs`，不进入桌面运行资源。

## 二、如何开始

1. 网页版刷新后，从主菜单进入海陆空试验区；桌面版使用下面的 **1.1.0 新 EXE**。
2. 在试验区开始/暂停面板中找到“飞行任务 · 归航试炼”。内容较长时向下滚动。
3. 点击“开始飞行任务”并再次确认。全部载具和试验路线会重置，任务直接从机场座舱开始。
4. Shift 增加油门、Ctrl 减少油门；鼠标与 A/D 引导航向，左右方向键滚转，C 切换视角，落地后空格刹车。
5. W/S 以当前反向设置和界面提示为准，开始任务不会重置该偏好。
