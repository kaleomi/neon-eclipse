# HUD 强化、战斗艺术字与单章挑战成就

## 用户确认的范围

- 外围 HUD 微偏移更明显；命中、击破与伤害数字采用更有力量感的艺术字风格。
- 继续上一轮 UI 缩放、面板密度及本地战斗报告导出方向。
- 纯刀按单章从头到尾、一命通关判定，不是六章战役总挑战。死亡或开枪失去本轮纯刀资格。

## 已完成

### HUD 与反馈

- 默认镜头跟随强度从原 1 倍提高至 2 倍：默认横向上限 10px、纵向 6px；菜单可选 1–3 倍，最大上限 15px/9px。保留平滑回中、暂停归位、系统减少动态效果和独立开关。
- 仅外围任务/武器/雷达/生命/弹药面板参与偏移和缩放；准星、命中射线、世界目标投影和交互位置不变。
- 命中使用青色、弱点命中使用金色、击破使用橙金色。斜切粗黑字、描边大伤害数字、切角底板、轻微冲击缩放、淡出与击破列表共同组成新的反馈风格。数字仍来自原有实际伤害统计；没有修改武器伤害或命中规则。
- 字体使用系统粗黑中英文字形回退和 CSS 艺术化样式，不依赖外部字体网络服务；没有冒称新增专门授权的字体文件。
- UI 缩放范围 80%–115%，标准/精简密度。精简隐藏任务列表中非当前项目和非当前武器的次要说明。小屏继续遵循既有安全布局。
- 显示偏好继续独立保存在 `neon-eclipse.presentation.v1`，兼容上一版仅含质量/动效开关的设置。
- 暂停/结算的本页战斗报告增加 JSON 下载按钮。报告含地图、阶段承伤/耗弹/时间/死亡位置/反击窗口记录；点击时生成，浏览器本地下载，不上传。记录本身仍不跨刷新保存。

### 五类成就

全部要求从章首开始并一命完成整章，不能用阶段训练、中途开始或加载检查点替代。

| 成就 | 条件 |
| --- | --- |
| 一刃破军 | 无枪械实发弹药，且至少用刀击破一个目标 |
| 毫发无伤 | 实际承伤为零；补血不抹掉承伤历史 |
| 不落战旗 | 一命通关，武器不限 |
| 全武装制霸 | 步枪、霰弹枪、手枪、刀分别至少击破一个目标 |
| 破核猎手 | 风暴港口一命通关，至少三名港务镇压者被暴露期胸核攻击击破 |

- 空枪也会取消纯刀资格；仅切换/装填枪械不算开枪。刀挥空不算枪械开火。
- 暂停继续保留本轮资格；死亡后的检查点重试不恢复资格。刷新后读取检查点也不计本轮挑战，可重新从章首开始。
- 荣誉殿堂显示规则、本轮开枪/承伤及获得过荣誉的章节。章首挑战按钮要求二次确认，并明确会重置本章检查点；不重置六章战役记录或星星记录。
- 成就使用独立 `neon-eclipse.chapter-achievements.v1`。写入前重读并合并已有记录，重复获得不重复登记；损坏数据不直接覆盖。存储失败不显示为保存成功，保留本页待保存结果并提供重试按钮。
- 原有四/五星老成就、六星收集和战役存档兼容逻辑保持不变。

## 主要文件

- `hud-motion.js`、`presentation.js`、`presentation.css`：增强偏移、缩放/密度、导出、设置兼容。
- `combat-ui.js`、`impact.css`：命中/击破/伤害字形与反馈。
- `chapter-achievements.js`：纯状态挑战资格、结算条件、独立持久化。
- `achievement-ui.js`：荣誉殿堂、挑战入口、保存失败重试。
- `app.js`：实发开火、各类承伤、实际击破/精英胸核击破、死亡、重试与整章结算挂接。
- `index.html`、`package.json`、`test-chapter-achievements.mjs`：接入与自动化回归。
