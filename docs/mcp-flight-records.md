## 如何使用

1. 打开载具试验区，开始“归航试炼”或“低空侦察”。
2. 完整成功后，结算界面提示本地保存状态。
3. 点击“查看任务记录”，或展开菜单中的“飞行成绩 · 本地档案”。
4. 查看各任务、各规则版本的完成次数、最好时间和最近五条成绩。
5. 保存失败时，留在本页处理问题并点击重试；重开任务不会主动丢弃本页待保存成绩。

仅从本版本开始产生有效成绩；没有可迁移的旧飞行成绩，不会补算过去的尝试。海战和自由驾驶暂不计入此档案。

## 有效成绩规则

- 归航：完整经过航路、进近、安全接地并完成停车，且未超时。
- 侦察：完整按序记录三个目标，返航进近、安全接地、停车并完成地面上传，且未超时。
- 失败、放弃、重置和自由驾驶均不计分。
- 每次开始产生独立尝试 ID，结算保留不可变的结果快照；重复回调或保存重试不会多记一次。
- 用时取游戏累计计时，保存为毫秒；暂停按既有游戏计时规则处理，不使用现实经过时间替代。
- 当前版本标记为 `return-v1`、`recon-v1`。不同任务、不同规则版本分别统计，不混合最好成绩。以后改变计分规则时必须更新相应标记。
- 这是本地规则校验，不是服务器认证或防作弊排行榜。

## 存储与故障保护

使用独立 IndexedDB 数据库 `neon-eclipse.flight-records.v1`，数据库版本 1，`attempts` 对象仓库以 `id` 为键。不会写入或清空六章战役、星星、成就存档。

- 同源页面的写入由读写事务串行处理，避免两页同时保存覆盖彼此。
- 同 ID、同内容重复保存视为成功去重；同 ID、不同内容报告冲突。
- 只有事务完成才提示保存成功，不把单次添加请求成功当成提交成功。
- 读取并校验历史数据后再写入。损坏数据或不兼容数据库不会被自动覆盖；界面明确显示“历史成绩未知”，而非伪装成零次完成。
- 容量不足、拒绝访问、无法使用或阻塞等情况有失败提示与重试入口。
- 写入提交后通过 BroadcastChannel 通知其他页面；另有窗口聚焦、页面重新可见和手动刷新作为补充。
- 最多保存 5000 条，不自动删除历史。达到上限后阻止新增，同一已存记录仍可幂等重试。

**重要限制：**

- 待保存队列只是本页内存；强制关闭、崩溃或确认离开后，尚未成功保存的成绩可能丢失。离开提示不是崩溃恢复机制。
- 已保存数据属于当前浏览器来源或桌面用户配置。更换域名、端口、浏览器、隐私窗口或设备不会自动共享；清理站点数据也会删除成绩。
- 本机完成时间用于最近记录排序，修改系统时钟会影响排序。
- 暂无云同步、成绩备份导入、损坏数据自动修复或历史清理界面。
