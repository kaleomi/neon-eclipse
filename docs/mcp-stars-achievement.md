# 四章星星与隐藏成就

## 当前规则（替代此前强制高架检修设计）

按用户最新要求，第三章东侧高架远端供电检修终端已删除，原位置替换为金色五角星。屋顶第三阶段清理守卫后直接接管天线控制柜，不要求运输行程或检修交互。楼梯、高架和运输平台保留，星星作为可选探索奖励，不阻挡通关。

四个现有关卡各一颗星星，同楼层靠近后自动拾取，不要求按 E 或消灭全部敌人。单章、战役和阶段重玩共享收集记录；死亡重试、重新开始或关卡切换不清空。集齐四颗后解锁隐藏成就「群星归航」，未解锁时名称显示 ???。菜单显示分章进度，战斗 HUD 显示本关收集状态与总数。

## 数据及文件

- `collectibles.js`：独立存档 `neon-eclipse.stars.v1`、白名单去重、楼层和距离判定、四颗解锁条件。
- `star-world.js`：旋转悬浮五角星、拾取、菜单/HUD、成就通知。
- `roof-data.js`：删除远端检修节点，更新第三阶段任务说明。
- `app.js`：接入实际运行更新，暂停时不拾取。
- `test-stars.mjs`、`test-random-repair.mjs`：收集规则及改版后的非强制运输主线回归。

星星坐标（开发验收用）：反应堆 (-33,-16), y=0；运输站 (28,8), y=0；屋顶 (32.5,17), y=3；中枢塔 (10,-8), y=6。未改动旧章节、战役或补给存档格式，也不会将过去的检修行为自动算为星星。

记录只在当前浏览器/站点本地保存，不是账号云成就。写入失败会提示，星星保留，可再次尝试；重复拾取不重复计数。成就属于收集奖励，不附带伤害加成或额外关卡。
