# P1 第二批：现有武器配置化与兼容注册表

日期：2026-09-17

依据：最新 `mcp-full-development-plan.md` 第 5.2 节，以及 `mcp-phase0-engineering-baseline.md` 的协作边界。P0 由另一位 AI 负责；本批继续 P1，不制作 EXE。

## 已交付

现有四把武器分别迁入 `weapons/vanguard.js`、`breacher.js`、`ghost.js`、`arc-blade.js`。新增统一 `weapons/registry.js` 和静态配置校验 `weapons/schema.js`。

- 每把配置包含稳定 ID、类别、历史数字索引、战斗参数。
- 历史顺序固定为 `vanguard / breacher / ghost / arc-blade`，仍对应 1–4 键；导入文件顺序不能悄悄改变历史槽位。
- `combat.js` 保留 `WEAPONS` 导出，所有原消费者无需改动。参数对象字段、数值、Infinity，以及原来未定义的 perShell 字段均由精确对比测试锁定。
- 默认定义不可变；`createWeaponProfile(id)` 返回独立可修改副本，为后续改装提供基础，修改副本不会污染默认配置或其他实例。
- 提供 ID/历史索引转换与定义查询；未知 ID 返回 null、未知索引映射返回 null、未知 ID 的索引为 -1，不静默换成另一把武器。
- 配置校验拒绝重复 ID/历史索引、非法类别、NaN/无限火器参数、非整数弹药、零攻击间隔、零火器装填时长、非法衰减与射击标记等。近战保留无限弹药、零装填。

**这是配置迁移基础，不是新增武器已经完成。** 目前仍四把全带；没有上线共享弹药池、改装、投掷物、额外伤害机制或新的携带限制。稳定 ID 尚未写入存档；历史存档格式和数字记录均未迁移。
