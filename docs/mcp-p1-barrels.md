# P1 反应堆爆炸桶试点与后续方案

2026-09-18。用户授权继续开发，并在选项中明确选择爆炸桶。仅源码，没有 Git 提交或 EXE；没有改动其他 AI 的 Boss 模块、载具、P0 runner/package。

## 已交付

- 反应堆侧翼两只红色工业桶，坐标 x=±19、z=18，不封主路。40 耐久；八种武器含刀、敌方弹体及返弹均能引爆。世界内标牌展示耐久、5m 危险半径和自伤警告；模型有金属箍、黄色警戒条，爆炸有短环形冲击波和粒子。音效复用现有低频重撞配方 `vehicle.impact`，未改音频总线；不是新录制爆炸音效，人工混音仍待验收。
- 三维中心距离线性衰减，半径5m及外部伤害为0；敌人基准峰值90、玩家峰值70，再走既有出/入伤倍率，敌人保留原身体护甲/HALO规则。不增加爆头或胸核奖励。当前试点明确不伤 Boss/独立装置，不能靠爆炸跳过 Boss 机制。
- 每次爆炸先冻结遮挡快照、算完目标，再改伤害和场景。实体墙、薄板、未破坏桶都能挡爆炸；同一脉冲击碎的薄板仍保护其后方。只修改自己拥有的碰撞条目，并使导航失效重算。
- 支持队列连锁，每桶只爆一次，连锁继承最后触发来源；试点两桶相距较远，自然场景并未布置连爆走廊，近距离连锁在真实模型世界夹具验证。击碎桶的弹体在桶处消耗，磁轨不能把厚桶当薄板穿透。
- 爆炸真实杀死普通敌人后清理弹体/模型并更新关卡敌人和全局击杀，不伪造任何武器击杀/开火。不会掉落补给、回血或补弹。
- **纯刀边界**：玩家主动引发的爆炸（包含刀/返弹触发和其连锁）实际伤到敌人时，记录独立 `environmentDamage`，本轮纯刀失效；不假增枪械开火，也不取消其他挑战。敌人引爆不记玩家开火/主动环境伤害，不记刀杀。刀仅破坏空桶、不伤敌时不因“引爆动作”取消资格，但自伤正常影响无伤挑战。成就进度和规则文案同步说明，历史荣誉存储格式未改。
- 暂停不推进引爆模拟；重试清空待爆队列、波纹并恢复安全初始布局。读档不新增桶字段；先移除桶再校验保存位置，玩家站在原桶位置时该轮跳过该桶。每次恢复也避让既有实体，防止新增桶与旧场景/旧存档挤在一起。爆炸桶位置和破坏状态不跨重试持久化。

## 后续开发方案（顺序与验收门槛）

### 1. 确认爆炸桶手感，封住归因与恢复边界

人工试射两侧红桶，观察爆炸/音量、自伤提示及敌人绕行；验证普通难度下是否有必要的战术价值。优先修阻断问题，不因自动化已通过就铺满九章；不随意调整已有武器数值。

### 2. EMP 能量节点（下一开发批次）

反应堆少量固定节点，世界标记明确可用/耗尽状态；复用既有机械敌人 EMP 关闭与恢复能力。先定触发来源、作用半径、遮挡与一次性/冷却策略，再接表现。重点验收普通人形不受瘫痪、Boss不被跳阶段、不会刷补给、暂停/重试/旧存档安全。不同时加入爆炸伤害与掉落。

### 3. 场景交互推广

前两类机制经人工确认后，先选一个额外章节，逐点核对现有掩体、导航、任务入口、自动检查点和 Boss 路线；与章节负责 AI 保持改动边界。每次只推广一个章节，先测自然路线与恢复，再扩展。此时再评估是否需要把薄板/桶/节点的表现适配器抽成更完整公共对象注册表，避免提前重构。

### 4. P1 战斗动作与武器深化

下一条独立战斗线建议普通敌人近战处决：条件/打断/动作/归因先闭环，Boss处决不纳入首批。之后分开处理武器改装、携带与弹药资源、重武器；先明确每项对八武器平衡和旧存档的影响，避免一次引入多套数值与新UI。处决、改装和重武器当前都未因此完成。

### 持续约束

保留霓虹工业风、既有全息HUD、世界任务目标；不复制底部任务信息。不修改他人Boss/P0基础设施，不做EXE，不拿别人测试当本批验收。九章真人连玩、长期平衡、实机性能和最终音频混音继续单列，不被上述源码增量替代。
