# 第六章：风暴港口 / 六章连续战役

## 已交付

按用户选择的 harbor + integrated-six 方案实现第六关，接在货运列车之后。新增菜单 06 / 风暴港口，可通过 `?map=harbor` 独立游玩，也可从连续战役进入。

五阶段：解除港区封锁 → 集装箱堆场取得吊机授权 → 三米吊机高架控制台 → 地面码头信标防守十八秒 → 三米接应船甲板撤离。

包含集装箱掩体、分阶段门禁、吊机及装卸高架、码头水域、固定靠泊接应船、雨雾和环境闪光。共有 21 名初始与增援守卫、8 处补给，沿用突击/远程/重装角色，没有新增 Boss。玩家与敌人可以经楼梯在地面、高架、船甲板之间移动。

独立隐藏星星在吊机旁三段窄平台的最高落点，高度依次 3.8、4.6、5.4 米。属于可选探索，不阻挡主线。

## 失败返回与边界

- 从星星最高点跌落到陆地后，可沿地面绕回吊机西侧楼梯。增加返回主路标识；没有封闭围墙落点。
- 码头东侧 x>24 且 z<-12 为水域。玩家落水到地面高度时，返回当前阶段入口，任务交互中断，生命、弹药和已保存星星不清空。
- 高处检查点与地面落点检查点都可恢复，未强制重开整关。
- 港口边界限制在 ±37.1 米，避免跨越低海堤进入未建模区域。
- 接应船固定靠泊，吊机为高架场景及任务设施；未实现船只驾驶、真实吊装、游泳或海浪冲击物理。天气主要是视觉效果，不会随机伤害玩家。

- `harbor-data.js`：任务、入口、刷怪、补给、碰撞、台阶、水域及星星平台。

- `journey.js`、`journey-ui.js`、`collectibles.js`、`star-world.js`、`levels.css`：六章入口、过场、结局和成就迁移。
- `train-data.js`：原第五章结尾改为章节完成，避免提前宣布全战役结束。
