## 测试边界

1. 九章恢复测试预置旧结构检查点，并受控触发失败；证明恢复链，不证明各章自然目标推进或全部 Boss 的实战通关。
2. 港口起点模拟防守已结束并清理此前敌人；起点之后的核心路线不直接写玩家位置、不写 Boss 血量，以键盘/鼠标输入、原生移动、机关和武器逻辑推进。
3. Boss 后主动失利与恢复是单独的检查点验收步骤。之后的守卫战和登船路线没有强制胜利、直接清敌或位置/生命夹具写入；正常游戏自身移动、伤害、拾取及检查点恢复不在此禁令之列。
4. 脚本精确转向/瞄准与冻结自动更新后的受控步进，并不等于人工操作难度、平衡或真实硬件性能验收。
5. 使用隔离浏览器配置，不清理用户实际存档。没有提交、推送或打包。
