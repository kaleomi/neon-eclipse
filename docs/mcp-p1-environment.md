# P1 追加交付：九章环境交互（排气阀冷却剂云 / 区域照明开关）（2026-09-19）

> 本文是本批实现与验证记录；当前状态入口仍是 `docs/mcp-project-status-roadmap.md`。Git 提交不是功能验收证据。

## 1. 范围与决策

- 用户批准顺序第④批：满足总体方案“每章至少 2 种环境互动”的硬性要求，同时不替换任何 Boss 场地、任务门、补给或刷怪点。
- 采用“两种共享机制 + 每章主题化命名与摆位”而非九套独立机关：可在一批内九章全部落地并统一验证；每章主题写在 `interaction-layouts.js` 的 `theme` 字段（如港口“消防雾化炮 / 码头探照灯”、列车“车厢制动排气 / 车厢照明”）。
- 已有的薄板 / 爆炸桶 / EMP 节点试点保留不动；本批只新增。

## 2. 规则（`interaction-rules.js`）

| 机制 | 数值 |
| --- | --- |
| 排气阀 `VENT` | 触及 2.2m、同层；按住 E 1.5s；喷射 5s，半径 3.2m；云内敌人速度 ×0.5 且无法开始预警；云内任何人（含玩家）6 HP/s；喷射后 12s 充压；松手归零 |
| 照明开关 `LIGHTS` | 触及 2.2m、同层；按住 E 0.6s 切换，单次按住只触发一次（闩锁）；黑暗时 ranged/sniper/commander 射程 ×0.65，stalker/hound 速度 ×1.25；再次按住恢复 |
| 叠加 | `environmentModifiers` 将两者相乘；Boss 不受云伤害（`app.js` 跳过 `boss`） |

## 3. 源码接线

- `interaction-world.js`：两座基座（进入 `obstacles` 作为碰撞，`interaction:true`）、喷嘴、地面环、半透明蒸汽柱；照明开关按需采样并精确恢复真实灯光强度（`HemisphereLight` + `DirectionalLight`）；`prompt()` 给出触及提示；`dispose()` 移除碰撞。
- `enemy-ai.js`：`createEnemyDirector({environment:{vent,lights}})`；速度、冲锋机冲刺、开火射程与“可否预警”按修正应用；`enemy.envSlow` 暴露给探针。
- `app.js`：`interactions` 在导演之前创建并传入；每帧 `update` 传玩家位置/楼层/E 键/忙碌；云内玩家走 `environmentHurt`、云内敌人扣血并按环境击杀清理（计 `environmentHit`，不伪造武器击杀）；触及时经 toast 提示；`reset()` 复位。
- `interaction-layouts.js`：九章摆位。

## 4. 验证

- 规则 `test-interactions.mjs`：按住/松手/忙碌/楼层/触及门；持续/充压/区域；开关闩锁与双向切换；修正器（减速、禁预警、黑暗射程/速度、相乘）；九章摆位对固体、已有试物、入口/目标/补给、所有阶段与防守刷怪排除区、列车车厢地板逐项断言。
- 集成 `test-interactions-world.mjs`：真实导演 + 真实模型：云内守卫半速且不预警、云外正常；关灯后狙击手 0.8 倍射程内不开火、潜行者提速 1.25，开灯后精确恢复灯光强度并恢复开火；九章布局构建/销毁。
- 浏览器 `test-interactions-browser.mjs`：九章真实页面，原生按住 E：排气阀启动并出 toast，云内守卫减速受伤、云外不受影响；照明开关关/开与真实灯光强度；重置清空。无页面错误。
- 全量 `scripts/run-tests.mjs --jobs 2`：451/451 check、105/105 rules、41/41 integration，退出 0；`get_diagnostics` 0。

## 5. 失败与修正记录

- 首版摆位由脚本按“试物旁 3m”生成，车站喷嘴撞上站台固体、列车尾车过挤（刷怪点/目标 2.5m 内）；改为按测试同一约束搜索，列车移到尾部 `-31/-27` 与 `13` 的车厢地板。
- 首版云中心距照明开关不足，玩家开关灯时被云伤害；加“开关触及圈在云外”断言并重新摆位。
- 首版把 `damageTime>0` 计入忙碌，导致刚被云伤到的玩家按不动开关；从环境交互的忙碌条件移除。
- 首版在构造时采样灯光基准，画质分档后续改动强度使“恢复”值错误（2.2 → 3.2）；改为关灯瞬间采样、开灯精确还原。

## 6. 未完成 / 边界

- 两种机制为共享实现，主题差异目前体现在命名/位置，不是每章独立机关模型；方案中“集装箱吊装 / 车厢解挂”等专属机关未做。
- 无真人手感 / 性能验收；软件 WebGL 浏览器用例为逻辑接线证据。
