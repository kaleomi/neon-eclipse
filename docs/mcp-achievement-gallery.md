# NEON ECLIPSE｜成就展示二期

日期：2026-09-17

## 本轮开发

沿用 `docs/mcp-hud-supplies-melee-progress.md` 的下一轮安排，不重复开发已完成的近战与挑战进度。

- 成就页加入全部章节、当前章节、六个指定章节筛选，以及全部/已解锁/未解锁状态筛选。
- 全部章节的已解锁表示任意一章已获得；指定章节严格根据该章历史记录判断。破核猎手只出现在全部章节或港口筛选下。
- 其他章节只展示历史荣誉，不显示当前章节的本轮进度，不触发地图跳转。重开按钮始终是重开当前游戏章节，不是筛选中的章节。
- 五类荣誉加入简洁符号徽章和展示称号：孤刃先锋、无痕行者、不屈战士、军械大师、核心追猎者。没有装备系统或属性加成。
- 新荣誉写入成功后显示 6.5 秒短提示，支持手动关闭。重复结算和无新增的重试不会再弹提示。
- 成就页可关闭提示；偏好独立保存在 `neon-eclipse.achievement-notices.v1`。写入失败时明确告知仅本页生效。
- 历史存储不可读或损坏时显示未知状态，不把读失败当成全部未解锁，也不覆盖旧记录。
- 改变筛选取消重开按钮的临时确认，避免误操作。

## 修改文件

- `achievement-ui.js`：筛选控件、历史列表、徽章、提示接入。
- `achievement-gallery.js`：只读筛选模型、展示称号、独立提示偏好和短提示组件。
- `challenge-progress.css`：筛选、徽章、短提示与窄屏布局。
- `test-achievement-gallery.mjs`：新增规则回归。
- `package.json`：把新增模块语法检查和规则测试接入 `npm test`。

现有战役、星星、成就存档格式及解锁条件不变。没有修改伤害、Boss 血量、关卡布局、近战范围或星星难度。Windows 项目未安装新依赖、未初始化 Git、未启动新游戏服务。

## 使用与后续

完成当前挑战后刷新原游戏页面，从首页或暂停页进入成就，即可使用新增筛选和提示开关。挑战中途刷新仍按原规则失去本轮挑战资格。

下一轮优先推进六章实际战斗反馈与可复跑的整游戏浏览器回归；港口末批压力、塔内楼梯和列车窄桥调整应依据实际承伤、耗弹和死亡位置数据。性能调优需先明确设备、分辨率和目标帧率；尚未实现本地存档备份/恢复或第七章。
