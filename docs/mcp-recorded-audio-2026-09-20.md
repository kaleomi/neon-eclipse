# 真实录音接入（2026-09-20）

用户试听 Sonniss 免费录音后授权接入游戏。本批将试听原件裁剪为 21 个单声道 44.1 kHz OGG，音频合计 684,271 字节。保留来源、原始文件路径、下载地址及原件/衍生文件 SHA256：`audio/samples/sources.json`；许可入口：`audio/samples/LICENSE.txt`。

## 已接入

- 越野车：汽车怠速与 Jeep 行驶录音随速度交叉混合；直升机：Bell 旋翼随 rpm 变速/调音量，停转静音；游艇：柴油船与水声。
- 舰炮/火箭发射、Boss/先遣队无人机爆炸使用火炮录音；装甲/墙面命中、碰撞和着陆使用金属/脚步片段。
- 主战役：按实际移动距离触发步伐，每种三种变化；极地使用雪地、港口使用碎石，其余使用金属。离地、菜单、重置和大幅位置跳变不触发步伐。
- 港口雨水、极地/屋顶/轨道基地风声、数据中心水声。按章节选材，并非逐三角形地表材质或动态天气完整混音。
- 录音与原音频总线共用音量、静音、暂停和后台挂起。切载具淡出；重试停止旧录音和旧合成音输出；迟到下载只缓存，不补播旧事件。
- 循环素材制作 350 ms 接缝交叉淡化；短音效淡入淡出，峰值归一后按事件增益混音。录音压缩在本地完成，无线上运行依赖。

## 范围

普通步枪/手枪、飞机发动机、UI/敌人预警、背景音乐仍为原有声音，本次素材未包含合适的全部替代物。不把火炮声冒充真实步枪录音。尚需用户在游戏中评价响度、循环和混音；自动化不是人工听感或硬件性能验收。

本批未打包 EXE、提交或推送。主入口仅增加地图和 grounded 音频事实，保留并行入口拆分工作。
