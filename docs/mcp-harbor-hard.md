# 风暴港口：高难度战斗优化

## 已实现

- 仅调整第六章遭遇配置。堆场两组长箱拆为保留掩体的分段布局，各留 3.2m 穿行缺口；两名守卫带独立包抄路径，完成后恢复常规角色战术。路径有超时退出，避免永久追逐旧路点。
- 信标防守从 18 秒延长为 24 秒：启动时 3 人，防守有效进度第 8 秒追加 3 人，第 16 秒追加 2 人（含精英）。离开地面九米防守范围不推进计时；所有批次到场且守卫全部清除后才进入登船阶段。增援沿西侧和北侧到场，不在防守圈内贴脸生成。全章共 26 名守卫，包括 3 名精英。
- 两座楼梯宽度从 2.4m 增为 3.2m；吊机平台向东扩宽 2m，不移动星星起跳边与窄平台。吊机守卫改为一名远程、两名突击，减少重型单位占位。修复混编队员避让后在楼梯底部折返的问题，保留原有顶部完成登阶和下楼出口路径承诺。
- 新精英“港务镇压者”：固定 230 HP，正面未散热时受到 35% 伤害；1.3 秒金色锁定预警后发射两轮三发扇射，轮间隔 0.35 秒、弹丸伤害 9，瞄准点不追踪玩家。射击完成后停止移动与攻击，青色胸核暴露 2.4 秒；核心伤害倍率 2.5，其他部位倍率 1.35。利用横移、掩体和散热窗口反击。
- 精英部署于堆场、码头末批增援、接应船。独立双枪轮廓、前胸核心变色与缩放；港口 HUD 显示预警/暴露状态和增援倒计时。

- 六章连续战役及原有存档键、存档迁移、已解锁旧成就保留规则。
- 六星收集条件、原有隐藏星星位置和跳跃序列；港口落水恢复、落地存档后绕回楼梯的返回路线。
- 第三章 Boss 1920 HP、节点与伤害；前五章遭遇配置；已修复的视角输入。
- 接应船仍为固定靠泊场景，未新增驾驶、航行或真实吊机物理操作。

## 关键实现文件

- `harbor-data.js`：遭遇、分批增援、包抄路线、掩体与平台几何。
- `harbor-navigation.js`：加宽后的登阶识别与底部进阶承诺。
- `harbor-elite.js`、`enemy-rules.js`、`enemy-model.js`、`enemy-ai.js`：精英状态、伤害、模型和战术接入。
- `mission.js`：按防守有效进度发出一次性增援事件，在完成判定之前处理到期波次，避免大 dt 跳批；重试重置波次。
- `app.js`、`harbor-combat-ui.js`：事件生成守卫、初始防守角色配置、港口战斗提示。
- `test-harbor-hard.mjs`、`test-harbor-combat.mjs`、`test-harbor.mjs`、`package.json`：新增与更新回归。

1. 优先按玩家实战反馈调整精英轮间隔、码头末批压力和补给余量，保持清晰预警，不再单纯堆血量。

3. 再做暴雨/弹丸/阴影的分档表现与实机性能测试，最后考虑第七章或额外挑战关。
