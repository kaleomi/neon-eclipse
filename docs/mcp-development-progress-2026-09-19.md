## 4. 目前最重要的缺口

### A. 内容闭环：先遣队与直升机

当前代码在 `expedition-model.js:12–20` 明确列出 5 关，并保留最终 8 关目标。需要继续完成第 6–8 关、直升机真实接入及第 5 关的撤离/恢复设计。是否扩展新载具、检查点和大地图演进，应按已确认范围分别验收，而不是只增加菜单入口。

### B. 产品体验：不是“功能有了”就结束

需要把九章、先遣队现有五关、P4 八模式的启动、自然流程、死亡重试、暂停恢复、存档恢复、成绩资格做成可追踪验收矩阵。已有部分人工反馈应保留其具体范围，不扩写为整体验收通过。

P6 优先补齐战斗/载具/档案页翻译与目标输入设备体验。触屏是否属于当前发行范围，需要先确认，避免不断扩大收尾范围。

### C. 工程与发行：证据尚未闭环

CI 工作流存在，不等于已在 GitHub 成功运行；本机帧时序采样存在，也不等于达到目标核显/独显帧率。后续需单独组织目标硬件采样、长时间稳定性和隔离配置的存档恢复验收。打包、签名、安装、发布只在用户明确要求后执行。
