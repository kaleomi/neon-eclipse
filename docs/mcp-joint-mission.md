# 海空接力｜连续任务首版交付

日期：2026-09-17

## 已完成并同步原项目

在既有载具试验区加入一条连续任务，而不是新的独立地图或第七章：

**领取设备 → 驾车到码头 → 换乘游艇 → 海上交付 → 返港下船 → 驾车到机场 → 换乘飞机 → 侦察返航上传 → 下机交接。**

九个阶段按顺序推进，保留场景目标名称、距离、离屏方向和侦察圆柱/扫描反馈。陆海空之间实际上下车、驾驶和步行，不在阶段交接时重置或传送载具。

遵守用户要求：**仅更新源码，没有生成 EXE，也没有修改既有桌面包。** 旧 EXE 不含本轮内容。

## 如何开始

1. 结束当前尝试后刷新网页版，进入载具试验区。
2. 点击“开始联合任务 · 海空接力”，再次确认开始。开始会重置全部载具、路线及原单项任务。
3. 跟随场景目标执行当前阶段。联合流程靠 **E** 自然换乘，不要通过菜单另开单项飞行任务。

| 阶段 | 操作与要求 |
| --- | --- |
| 领取设备 | 步行进入终端范围，按住 F 1 秒 |
| 陆路到码头 | 必须使用越野车，在目标停车区停稳 2 秒 |
| 登船 | 下车，沿栈桥步行，靠近游艇按 E；仍遵守原安全登船判定 |
| 海上交付 | 驾驶游艇抵达交付浮标，停稳并按住 F 2 秒 |
| 返港 | 靠近原泊位停稳，按 E 安全下船；留在船上不能进入下一阶段 |
| 陆路到机场 | 沿栈桥回岸、回到原越野车，在机场停车区停稳 2 秒 |
| 换机 | 下车绕过越野车，靠近停在机场的飞机按 E；自动接入侦察段 |
| 侦察返航 | 完整扫描三处目标、北向进近、安全着陆、停车并上传；保留五分钟飞行限制 |
| 最终交接 | 安全下机，步行到返航终端按住 F 2 秒，整项任务才完成 |

本轮设备领取与交付是抽象交互，不包含搬箱动画、新敌人或新增战斗。

## 状态、安全与成绩

- 当前阶段控制可进入的载具类型，不能通过提前登机跳过海上任务。
- 停稳与持续交互条件一旦不满足，当前保持进度清零。
- 侦察段不调用会重置载具的单项任务入口，而是在实际登机后接入。
- 只有完整有效的侦察结果、且尝试 ID 与本次飞行相符，才允许进入最后交接；重复结算不能重复推进。
- 联合任务中的飞行成功不写入归航/侦察单项成绩。原单项任务仍按原规则保存成绩。
- 暂停会冻结联合任务计时。活动联合任务中禁用按住 R 快速回收。
- 菜单回收、试验调度、切换单项任务会中止并重置联合任务；另有确认中止入口。
- 飞行失败会结束联合任务；当前需要重开整轮。

## 重要限制

这是连续任务的首版：**只有本页进度与结算，没有检查点、跨刷新恢复或联合成绩档案。** 刷新、离开或重开会丢失本轮阶段。战役、星星和既有飞行成绩不会因此被清空。

其他阶段没有总倒计时，飞行段仍沿用五分钟规则。基础试验区的部分自由路线布景/浮标仍保留，请以联合任务当前场景目标及阶段提示为准。

## 接下来的开发方向——尚未实现

### 第一优先：安全阶段检查点

在领取、海上交付返港、机场交接等安全节点保存必要状态，失败后能恢复最近阶段，避免每次飞行失败都重跑全部陆海流程。只恢复安全停放与交接状态，不保存半空失控瞬间。保存独立于六章和单项成绩，明确中途恢复的成绩资格。

### 第二优先：换乘与交接体验

减少无关路线标记干扰；强化泊位方向、下船位置和绕车路径。逐步补设备交付反馈及阶段完成表现，根据真人游玩确认距离、提示和停车窗口是否合适。

### 第三优先：数据保障与实机测量

加入备份、校验与恢复预览，再测目标设备的帧时间和长时间内存趋势。不扩开放世界或第七章，不夹带联机与云排行榜，继续只交付源码。
