# 稳定性第一批：音频重试状态与波浪声静音修复

日期：2026-09-18。接续 `docs/mcp-stability-plan.md` 的 S7；当前进度入口：`docs/mcp-project-status-roadmap.md`。本轮只修复已复现的音频生命周期问题，不新增玩法、不改任务/武器/物理数值、难度、成绩资格或存档格式，不制作 EXE。

## 已定位与修复

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| FPS 重试/恢复可能把旧天气状态误当作新提示边沿 | `chapterCues` 有 reset，但 `app.js` 的会话 reset 没调用 | reset 开始时清空提示基线，首个新快照保持静默 |
| 连杀计数及延迟提示可能跨新行动残留 | `gameAudio.reset` 未接线，且不撤销 120 ms 延迟回调 | 会话 reset 调用音频 reset；音频门面跟踪并取消本轮尚未触发的连杀定时器 |
| 载具重新调度/任务重试继承旧碰撞计数和失速间隔 | 音频只重置事件计数接口，没有完整会话 reset | 新增 `vehicleAudio.reset()` 并在公共 recover 接入，重置事件基线、载具类型、碰撞计数与失速计时；保持 pause/hidden 持有原因与音量设置 |
| 非水域或 inactive 状态下波浪声可能绕过零增益 | LFO 加性调制直接接最终 waveGain 的 AudioParam，设为 0 仍被周期调制 | 将 LFO 接到独立上游调制层；最终 waveGain 单独控制波浪声包络，使零目标增益不再被调制绕过 |

载具 `finishFlight`、`finishJoint`、`finishEscort`、`finishChase` 原本已调用 pause，本轮没有重写结算，也没有宣称这些路径此前缺失暂停。增益使用既有平滑时间，不声称样本级瞬时静音。未改变现有一次性音效的正常自然尾音。
