# 六章整体表现优化：HUD、光影、性能分档、阶段统计

## 已实现

- 保留青蓝全息风格，收敛边框光晕、扫描纹理和面板透视角度，增强文字对比，压缩武器侧栏；小高度窗口简化非当前目标列表。
- 外围任务栏、武器栏、雷达、生命/弹药面板跟随镜头转动轻微惯性偏移：横向上限 5px、纵向上限 3px，停止转动后平滑回中。使用独立 CSS translate，不覆盖原有面板 transform。不移动准星、命中反馈、世界目标投影、交互提示，也不改变鼠标输入与相机瞄准。
- HUD 动效提供独立开关；暂停、无效角度和系统 prefers-reduced-motion 生效时归位，避免重新锁鼠标时积累位移。
- 六章共享冷色主光和低强度暖色补光，调整曝光为 1.07，保持各章雾浓度不因性能档位改变，避免低画质通过加浓雾遮挡敌人。
- 三档画质，通过 Q 或菜单切换并保存偏好：性能档像素比上限 0.8、关闭环境阴影/环境 Points；均衡档上限 1.25、环境 Points 绘制半数、关闭阴影；精细档上限 1.5、完整环境 Points、1024 PCF 柔化环境阴影。初始默认均衡，像素比不超过设备 DPR。武器、弹丸、敌人、交互对象与碰撞规则不按质量档删减。
- 阴影用于启动时已有的不透明环境网格，不给第一人称武器投影；本轮未增加所有动态敌人的接触阴影、SSAO、Bloom 或反射后处理。环境粒子分档减少绘制量，不宣称已重写所有粒子 CPU 更新。
- 暂停页改为优先展示继续行动、画质、HUD 开关、战斗记录，地图/战役入口仍在下方，菜单可滚动；960x640 下验证主操作与设置可达。
- 新增本页阶段/重试记录：有效游戏时长、实际承伤、实发弹药、死亡的 x/z/脚底高度、精英散热窗口开启数及利用数。一次窗口内多次胸核命中只算一次利用；统计不是命中率。霰弹按弹药消耗而不是弹丸数计数，近战不计耗弹。
- 记录在暂停/胜负菜单折叠展示，最多 100 条，去除未开始的空记录。本页内跨重试保留，刷新/跨页后清空；未新增数据上传或持久化战斗日志。显示偏好单独使用 `neon-eclipse.presentation.v1`，读写失败有内存降级，不改旧战役/星星存档。

## 代码位置

- `hud-motion.js`：纯偏移状态，限幅、平滑、异常/暂停复位。
- `presentation.js`：共享光影、质量档位、设置存储、HUD 偏移与暂停报告。
- `presentation.css`：统一精修、响应式、暂停操作层级。
- `field-record.js`：阶段统计、不可变读取、有限记录数。
- `app.js`：表现层、实发射击/承伤/死亡/阶段事件挂接；帧 dt 非负保护。
- `enemy-ai.js`：可选精英窗口开启回调，原始战斗时序不变。
- `index.html`、`package.json`、`test-presentation.mjs`：样式接入与新增回归。
