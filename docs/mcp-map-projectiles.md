# 扩展地图与敌方弹道

## 地图

从 48×48 扩展为 80×80，地面面积约为原来的 2.78 倍。arena.js 为边界、出生点、掩体和美术共用配置。保留中心反应堆；增加西侧冷却区、东侧仓储区、南部部署区，掩体从 6 个增加到 18 个。玩家部署点为 (0,29)，敌人从多个方向出生，出生距离至少 14。普通波次 5–8 名守卫，最终波为 Boss 和 5 名守卫。

扩展了地板、墙面、灯带、顶部管线和标识；新增共享 BFS 流场导航，保留精确移动碰撞。宽屏（至少 1100×750）显示战术地图，标出玩家、敌人、掩体和飞行弹丸；小屏隐藏地图以免挡住战斗视野。

## 敌方弹道

projectiles.js 取代原有瞬时扣血：普通敌人蓄能 0.45 秒后发射橙红色弹丸（速度 18），Boss 蓄能 0.65 秒后发射粉红三连扇形弹（速度 15）。弹丸带明亮核心、光晕和立体曳光，寿命 4 秒；同时飞行上限 96，蓄能上限 16。

蓄能期间敌人停步；攻击方向锁定于蓄能开始时的玩家位置，不追踪玩家。玩家可横移闪避，掩体能阻挡射击。只有实际碰撞才扣血（普通 6，Boss 每发 10），并显示命中火花。collision.js 使用线段扫掠检测，优先处理路径上的掩体，避免低帧率时穿墙或穿过玩家。玩家移动也参与相对扫掠检测。暂停冻结弹丸，换波、重开、胜负状态清理弹丸和预警；敌人被击破会取消未发出的弹丸。

## 验证

- test-core.mjs：线段与 AABB/球体相交、80×80 边界、新区可通行、出生点安全及 40 条大型敌人导航路线通过。npm test 运行上述测试并检查各模块语法。
- 独立 Chromium：预警、延迟发射而非瞬时扣血、弹丸实际命中、掩体截断、横移躲避、Boss 三连弹、寿命/清理、暂停冻结测试通过；无页面 JS 异常。
- 原有射击、换弹、武器切换、装甲命中、掩体遮挡、波次推进、最终 Boss、胜利和重置回归通过。波次测试为受控状态推进，不等同完整人工通关。
- 仍需在 Windows 硬件加速环境试玩，确认扩大地图后的难度与长时间性能；低配置可按 Q 切换性能画质。

## 运行

已有本地服务时 Ctrl+F5 刷新 http://localhost:5173；否则在项目目录运行 npm run dev。操作键不变。
