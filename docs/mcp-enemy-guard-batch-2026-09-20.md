# 第二批角色模型交付：A–03 RIFT / H–12 BASTION

- 日期：2026-09-20
- 项目：NEON ECLIPSE
- 范围：突击守卫 `assault`、重装守卫 `heavy`；已确认的 R–07 原样保留。

## 1. 本批交付

这次不是更换颜色，而是两套独立的装甲轮廓、头盔、装备与刚性关节动画。

- **A–03 RIFT · 突击守卫**：收束肩甲、较轻的分段护甲、橙色双目、外露机械结构和短枪；巡逻动作更快。
- **H–12 BASTION · 重装守卫**：宽肩厚甲、内嵌单目、叠层胸甲与三联发射器；背部保留醒目的绿色核心，步态更沉重。
- **R–07 VIGIL · 对照模型**：源码、运行时适配器、GLB、清单、构建脚本和原独立预览均未改动，已核对原交付哈希。

两款都是原创硬表面机械装甲模型，采用刚性节点动画，不是真人蒙皮角色，不含人形骨骼重定向、布料或面部绑定。

| 项目 | A–03 | H–12 |
| --- | ---: | ---: |
| 版本 | `a03-v1` | `h12-v1` |
| GLB 文件 | `assault-guard-a03.glb` | `heavy-guard-h12.glb` |

网格批次数不等同于包含阴影等渲染通道后的总 draw call 数。

四个动作均随 GLB 内嵌，每个动作含 14 条轨道：

- `Idle`：2.4 秒。
- `Patrol`：A–03 为 0.65 秒；H–12 为 1.25 秒。
- `Aim`：2.4 秒。
- `Hit`：0.5 秒。

坐标约定为米制、+Y 向上、+Z 向前。重装兵沿用游戏原来的 `1.12` 实例缩放，未把该缩放烘焙进 GLB。动作节奏不同不代表修改了实际移动速度。

## 2. 如何查看与使用

通过项目现有 HTTP 服务器访问 **`/enemy-roster-preview.html`**，不要直接以 `file://` 打开。

预览支持：

- 三人编队对照，以及 A–03 / R–07 / H–12 单独查看。
- 待机、巡逻、瞄准、受击四个动作。
- 鼠标拖动、滚轮缩放、自动旋转、暂停和线框。
- 正面、四分之三视角，以及重装兵背面弱点查看。
- 两款新模型的 GLB 下载。
- 窄屏布局；390 像素视口已检查。

预览复用项目已有 Three.js，不依赖 CDN，也没有覆盖游戏 `index.html` 或修改 `package.json`。游戏中自然生成的这两类敌人已经使用新外观，重新加载游戏页面即可生效。

## 3. 接入边界与战斗规则

游戏业务代码仅在 `enemy-model.js` 增加导入、工厂选项、类型接入和动画钩子四处小改动。造型、导出和资源加载逻辑放在独立模块中。

保留原来的直接子级命中 Mesh，隐藏其显示但不移动或重建其判定形状。新外观作为子树挂载，装饰 Mesh 不参与战斗射线。保留原 `hitZone` 和命中对象的直接父级归属。

没有改动 HP、伤害、射速、移动速度、AI、碰撞半径、关卡、玩家武器、Boss、存档或其他兵种。本批也没有提交、推送或发布整个项目。

重装兵保留原规则：

- 正面朝向判断满足原阈值时，非核心命中只承受 **30%** 伤害。
- 侧面 / 背面普通部位承受正常伤害。
- 命中核心为 **2 倍** 伤害。
- 旧核心为半径 `0.21`、detail `1` 的二十面体球，模型坐标中心为 `(0, 1.28, -0.6)`。
- 新 `H12_CoreSocket` 直接挂在视觉根节点下，中心和可见核心尺寸对应旧弱点，不跟随胸部呼吸或步态漂移。

调试时可用 `createEnemyModel(type, {guardBatch:false})` 对比旧外观，或用 `{loadGuardAsset:false}` 强制使用同源程序模型；这两个选项不改变命中和战斗规则。

## 4. 加载与资源生命周期

- 每个兵种独立缓存一次 GLB 加载任务和模板。
- 首次加载期间显示同源程序模型，加载成功后替换外观；已有缓存时直接克隆 GLB，不重复制作程序外观。
- 每个实例拥有独立的几何与自有材质，角色指示灯和核心继续绑定原有材质。
- 替换外观只释放旧外观拥有的资源，不释放共享角色/核心材质。
- 已从场景移除的旧实例不会在异步加载完成后重新挂回场景。
- 资源 404 时保留可见、可命中的程序化回退，不会把敌人变成不可见目标。失败任务在当前页面内缓存；资源恢复后重新加载页面可重试。
