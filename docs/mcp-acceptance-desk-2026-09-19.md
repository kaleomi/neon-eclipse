## 操作方式

1. 在“本轮设置”填写构建标签、设备、浏览器、画质与验收人。
2. 选择用例及难度/变体，通过原生试玩入口进行实际体验；先遣队需按正常顺序推进，P4 从行动中枢创建行动，不伪造行动 ID 或改写游戏进度。
3. 逐项勾选后才可标“通过”。“不通过”“阻塞”“跳过”必须填写原因；取消已通过的检查项会撤回通过判定。
4. 导出 JSON 交回助手，截图作为独立附件；JSON 可重新导入，Markdown 用于阅读和归档。

## 保存与安全边界

- 只读写验收台专用的 `arena.neon-eclipse.acceptance-desk.v1` 键，不读取游戏存档，不使用 `localStorage.clear()`。
- 不自动向任何服务器上传或抓取数据；游戏链接只在用户点击时打开。
- 记录包含各用例的版本/环境快照、难度、检查项、结论、备注、影响程度和证据文件名。切换难度不互相覆盖。
- 无法使用本地存储的预览/隐私环境会明确提示临时记录，并可导出或手动复制。
- 嵌入预览不尝试绕过弹窗/网络限制，而是显示可复制的本机地址。
- 导入仅接受本验收台 schema 1 JSON，限制 3 MB，校验通过记录的检查项完整性与必填原因；确认后替换验收记录，不导入游戏备份。
- 服务地址只接受无账号密码的 HTTP/HTTPS；备注及导入文本按文本显示，不作为 HTML 执行。
- 新建一轮需要输入“新建一轮”二次确认；换浏览器/站点或清理浏览器数据前请导出。
