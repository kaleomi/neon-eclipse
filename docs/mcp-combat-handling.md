# 战斗手感迭代

## 武器与瞄准

combat.js 集中定义武器参数、伤害衰减、散布和后坐力。步枪为按住连射；霰弹枪、手枪和能量刃为单击触发，短按输入保留 0.18 秒缓冲。切枪有 0.22 秒举枪时间，不能用切枪取消射击冷却。

后坐力使用可回正的镜头偏移，不修改玩家基础瞄准方向；连射有累积上限，停止射击后回稳。右键平滑进入瞄准状态，降低移动速度、鼠标灵敏度、散布和后坐力。移动和连射扩大散布，动态准星同步提示。菜单可调整灵敏度 0.5–2 倍（仅当前会话，不持久化）。冲刺仅在移动且未瞄准、射击或换弹时启用。

## 换弹与反馈

- 换弹倒计时、进度条和枪体下压/回位动画；完成时播放就位声音。
- 切枪取消未完成换弹，不转移弹药；暂停时进度冻结，继续后恢复。
- 头部/面罩为弱点：步枪 1.75 倍、手枪 2 倍、霰弹枪 1.25 倍；近战无头部加成。
- 枪械按距离衰减伤害；霰弹枪远距离衰减更明显。
- 命中伤害汇总、弱点和击破色彩区分、最多三条击破提示；每枪只触发一次命中音效，避免霰弹枪八次声音叠加。
- 来袭方向弧线根据弹丸发射位置和当前视角计算，同时最多四个；低血量和弹药不足有提示。
- HUD 显示 AUTO、SEMI 或 MELEE 开火类型。

## 敌方节奏

保留可躲避弹丸与普通 0.45 秒、Boss 0.65 秒蓄能。增加敌人之间的开火间隔门控：普通攻击间隔至少 0.28 秒，Boss 开始蓄能后至少 0.55 秒才允许下一个敌人开始攻击。普通敌人自身攻击间隔为 2.1–2.9 秒，Boss 为 2.1 秒，减少同时齐射。未新增敌人类型，也未改变地图规模。

## 验证

- test-combat.mjs：伤害衰减、弱点倍率、瞄准/移动散布、后坐力上限与回正、举枪锁定及不同步长下的指数回正一致性通过。
- test-core.mjs：地图边界、扫掠碰撞和 40 条大型敌人路线通过。
- 独立 Chromium 受控测试：连射、单发武器长按只开一枪、取消换弹不吞弹/刷弹、正常换弹转移、实际头部命中、击破反馈、瞄准过渡、敌人错峰开火、来袭方向、暂停换弹并恢复通过；无页面 JS 异常。
- 原有弹丸蓄能、飞行命中、掩体截断、闪避、Boss 扇形弹、暂停冻结和波次状态回归通过。波次测试是受控推进，不是完整人工通关。

需要 Windows 实机试玩进一步调整手感与难度；不宣称软件渲染测试代表实机帧率。npm test 包含语法和纯逻辑测试，浏览器测试未加入项目依赖。已有服务时 Ctrl+F5 刷新 http://localhost:5173 即可。
