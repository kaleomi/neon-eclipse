## 历史文档规则

其余 `mcp-*.md` 专项记录默认是各批次当时的快照；“未实现”“下一步”和测试计数不能自动当作今天的结论。冲突时先核对当前源码、明确关联版本的验证证据，再更新当前状态入口。不删除旧失败记录，不把后来的功能或复测伪写成早先已经完成。

阶段交付不等于发行验收。源码已接线、规则通过、浏览器通过、人工通过、性能通过分别记录。Git 只保存变更历史，不作为功能完成证明；提交前保留其他会话的工作边界。
